# 课程界面清理与分镜复核

日期：2026-10-21。

本轮检查首页、课程目录、学期目录及课程页面，并逐幕核对现有 4 份分镜、2 份视频 JSON 与对应讲授稿。讲授稿和练习单正文保持原样；分镜文件和制作资料全部保留。

## 学习界面

- 首页移除介绍口号和视频制作状态，只保留年级、课程名称与入口。
- 学期目录移除“待教师复核”、文本进度、制作顺序、重复标题及方案区入口。
- 课程页移除“待渲染／先看分镜稿”占位卡、分镜入口和视频规格说明。有视频就显示播放器，没有视频就直接显示课程。
- 保留课程讲解、动手练习、挑战单、打印、目录和回到顶部。补上从课程到动手练习的直接入口，避免移除分镜入口后找不到练习单。
- 制作与审查资料仍在原目录，未从项目中删除；不出现在学生学习入口中。
- 改动已落在 HTML 生成模板，重新构建后不会恢复这些过程信息。

## 分镜发现与修复

| 课程 | 原问题 | 本轮处理 |
|---|---|---|
| L01 满十进一 | 把假设性的数数故事当作历史事实；“十进制来自十根手指”表述过于确定；五进制挑战不属于当前课；分镜与 JSON 旁白已有差异 | 改为直接操作小棒；改用课程中的 305、99+1 和 0、3、7 组数题；增加 730、307 的答案画面；同步分镜、JSON、配音和字幕 |
| L02 竖式的秘密 | 715 错误示范容易被当成正确竖式；挑战让孩子“再看答案”，却没有答案幕；制作说明误以为现有加法场景能直接处理进位、借位 | 错误示范始终标错；补上 100−28=72 及“9 个十、10 个一”的借位过程；明确钱币交换、加法进位、减法借位场景仍需实现 |
| L03 乘法的形状 | 未明确转向是否算新摆法；提前用“因数”解释而没有铺垫；提前引入面积；24 个小方块挑战无答案；主课视频没有覆盖后来增加的三位数乘一位数短课 | 改用行数与每行数量；明确 12 个棋子按行列分开算 6 种、转向算同种为 3 种；加入本课 6×7、25×4；明确 24 个小方块转向算同种共 4 种，并给答案；补充独立短课分镜，标明该段尚未制作 |
| L04 除法的两张脸 | 原制作说明“3 个一圈或 3 个一堆”不能正确区分两种除法情境；17÷5 挑战没有后续答案；“剩一颗还能装一袋吗”没有强调每袋装满 3 颗 | 明确平均分为 3 碗×4 颗，按每袋 3 颗分为 4 袋×3 颗；补上 17÷5 的两幅答案图、余 2 颗及 5×3+2=17 检查；说明余糖不够再装满一袋 |

L02、L04 已核对算式、数量、单位、答案与分镜要求，仍是待制作稿，没有将其标记为已生成成片。L03 的“三位数乘一位数”是另一段待制作短课，现有主课视频只讲点阵与交换律。
