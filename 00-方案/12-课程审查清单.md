## 每课检查八项

| 项目 | 核查重点 | 不通过的例子 |
|---|---|---|
| 数学正确性 | 定义、计算、单位、条件、量词 | “某个”误作“任意”；充分条件误作必要条件 |
| 先修知识 | 本课实际使用的运算、符号和图形知识 | 五上默认已会通分；小学证明依赖未教的整式展开 |
| 教学过程 | 讲解、示范、独立题能否连起来 | 只给答案，没有小数除法逐位示范 |
| 图示与读图 | 顶点、方向、刻度、单位、图例是否准确可读 | 左视图高度错误；只给表格就声称会读折线图 |
| 题目条件 | 条件能否确定所问答案；开放题允许多个解 | 盒子不说有无盖；人数相加未排除重叠 |
| 解法评价 | 区分错误、正确但较繁、题目限定方法 | 用公分母 48 被判错；等式两边整体先除被判错 |
| 独立迁移 | 验收题是否有新条件组合、解释与判分依据 | 把刚讲过的原题原数值当作 C 层挑战 |
| 年龄与负担 | 语言、步骤和符号是否适合当前学生 | 将进制、一般扇形公式或负数运算作为默认必修 |

## 学习安排

- 以文本、图示和例题为主；动手单属于可选材料，不要求家长购买器材或带做实验。
- 补充短课可以另次学习；不承诺所有内容统一在 75 分钟内完成。
- 诊断已掌握的内容可跳过；没有学过的前置先补，不把尚未教学算成孩子能力不足。
- 三集合、其他进制、一般扇形面积和弧长、负数运算按课内标记选学。选学内容不作为成都 B 卷统一覆盖证据。
- 折线统计图在五下先学；六下做图种选择和跨图综合。

## 容易复发的边界

| 内容 | 核对标准 |
|---|---|
| 分数比较 | 纯数可以直接比大小；不同整体的实际部分量另算 |
| 小数性质 | 在小数末尾添 0 或去 0，数值不变；不能随意插入到小数点后 |
| 循环小数 | 同一除数下看余数状态；余数为 0 终止；区分非循环前段 |
| 方程 | 对两边整体作等价变形；同除的数非 0；解方程不能同乘 0 丢掉信息 |
| 分数乘除 | 除数非 0；带分数先解释成整数与分数的和；不能把推荐写法说成唯一合法算法 |
| 比例 | 比的后项非 0；正比例判断与题目指定 k 的方向分开 |
| 圆锥 | 等底等高能保证 1/3；底高不同仍可能碰巧有相同体积比 |
| 容积 | 说明内部尺寸或盖、底、壁的厚度；排水题说明完全浸没、不吸水、不溢出 |
| 找次品 | 先说明次品已知轻/重，还是轻重未知 |
| 鸽巢 | “至少”表示最坏情况下仍可保证，不表示每个抽屉都满 |
| 负数与楼层 | 认识基准和顺序；现实楼层有无 0 层须单独约定 |
| 百分数与统计 | 说清比较的整体；跨图必须确认对象、时间和总量对应 |
