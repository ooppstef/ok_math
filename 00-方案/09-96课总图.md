# 三至六年级 96 课总图

8 个学期，每学期 12 课，共 96 课。三、四年级的细节在 [01-48课知识地图](01-48课知识地图.html)，五、六年级在 [08-五六年级48课地图](08-五六年级48课地图.html)。

## 一张表看八个学期

| 学期与主线 | 12 课 |
|---|---|
| 三上 · 位值、竖式、乘除、周长 | 满十进一、竖式、乘法的形状、除法的两张脸、倍、0、估算、单位、周长、分数初步、集合、时间 |
| 三下 · 面积、小数、年月日、搭配、周期、植树 | 除法竖式、两位数乘法、面积、周长与面积、面积单位、小数、年月日、方向、搭配、统计表、周期、植树 |
| 四上 · 大数、角度、积商规律、优化、容斥 | 大数、进制、角度、平行与垂直、三位数乘法、积的变化、试商、商不变、图形稳定性、优化、容斥、数字谜 |
| 四下 · 运算律、小数性质、三角形、统计、鸡兔、行程 | 运算顺序、运算律、简便计算、小数意义、小数点移动、三边关系、内角和、图形运动、平均数、鸡兔同笼、行程、建模 |
| 五上 · 小数、方程、多边形面积、植树 | 小数乘法、小数除法、循环小数、数对、可能性、字母表示数、等式与方程、列方程、平行四边形面积、三角形面积、梯形面积、植树 |
| 五下 · 因数倍数、长方体、分数、旋转、找次品 | 因数与倍数、2/5/3 的倍数、公因数与公倍数、观察物体、旋转、长方体与正方体、表面积、体积与容积、分数的意义、分数基本性质、分数加减、找次品 |
| 六上 · 分数乘除、比、圆、百分数、统计、数与形 | 分数乘法、分数除法、比、按比分配、位置与方向、圆、圆的面积、扇形、百分数、百分数应用、扇形统计图、数与形 |
| 六下 · 负数、百分数（二）、圆柱圆锥、比例、鸽巢、复习 | 负数、折扣利率税率、圆柱表面积、圆柱体积、圆锥体积、比例、正比例、反比例、比例尺、鸽巢、统计图选择、整理复习 |
