## 循环记录

本轮沿用 loop-review-fix 的至少三轮机制。课程修订按用户授权改变错误教学内容；网页代码复用现有 Markdown 渲染器，不新增框架或依赖。每轮同时检查过度防御、过度设计、兜底、假想复杂性、无用代码、现有能力复用。

### 第 1 轮：按问题清单修复

范围：20 号 N01–N18、相关讲授稿与配套单、覆盖表与当前审查规则。已落实数学条件、学习顺序、短课和图表。16 组精确算术检查、8 份 SVG 结构检查、JavaScript 语法与差异空白检查通过；链接检查发现并修正了报告中的两个课名路径。本轮有修复，不是无问题轮。

### 第 2 轮：独立复查教学链和配套页面

复查了三至六年级本轮课程差异、完整新增短课及配套挑战。发现并修正：带分数乘法的过强限制；积商比较缺少正数条件；换容器题缺少柱形条件；长方形对称轴没有排除正方形；三下例题仍用两位数除法；单位错误的倍数被一概而论。补入覆盖表中尚缺的六条教学链，补完整小数竖式，将并排统计图改为上下排以便手机读图。本轮有修复，不是无问题轮。

验证：新增 7 组精确计算／枚举检查通过；执行一次现有 `npm run build`，生成 167 项页面输出；167 个页面的本地文件和锚点检查无失效链接。浏览器在 390 与 1365 像素宽度检查了 24 个场景，未见页面横向溢出或图片加载失败；目视复查所有课程图、两组乘法竖式和两组小数除法竖式。按检查结果放大了图表标注。

### 第 3 轮：最终差异与回归复验

复核 N01–N18 的证据、反例和配套页面。9 组边界反例检查通过，包括圆锥量词、楼层有无 0、分数与实际数量、不同合法算法。

发现网页生成注册遗漏：五上 04/08/12、五下 04 的挑战单没有登记到 `工具/build_html.js`。其中本轮已改的列方程、植树挑战在 Markdown 中更新，HTML 仍显示旧题。已用现有 `DOCS` 注册方式补齐 4 项并定向生成；没有再跑全量构建，也没有新增发现机制、依赖或渲染器。

复核这四份独立材料时，同时把数对座位题的方向约定移到题干，并明确观察物体题的 T 形是一层摆放。它们需要在脱离讲授稿时也能确定答案。本轮有修复，不是无问题轮。

### 第 4 轮：生成入口与完整修复集复验

重新检查最终课程差异、四份挑战单完整内容、网页注册与渲染调用、图像引用和三轮修复证据，未发现需修复项。没有修改课程或构建代码；结束后只补写本记录。

- 全部课程 Markdown 已有生成入口，显式注册无重复；四份遗漏挑战单均已生成，能看到当前题干与答案。
- 将本轮改动对应的文档和目录交给现有渲染函数，在内存中与磁盘 HTML 对照：75 页全部一致，没有再次执行全量构建。
- 171 个改动／新增页面的本地文件和锚点有效；10 张课程图均有实际引用，无孤立图片。
- 最后定向检查 4 份挑战单和方格图的手机、桌面显示，共 10 个场景，未见横向溢出、图片加载失败或旧题残留；各轮累计检查 34 个浏览器场景。
- 复用前轮已通过的 16+7+9 组精确计算、枚举和边界反例结果；最终源文件校验值未变，JavaScript 语法及 `git diff --check` 通过。

最终无问题轮为第 4 轮。这里的“无问题”限定于本轮修复范围和上述验证，不表示证明整个课程没有任何问题。
