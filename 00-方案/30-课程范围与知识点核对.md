# 三至六年级课程范围与知识点核对

核对日期：2026-10-21。对象：成都通用，当前重点为高新区三年级；以北师大版为教材参考方向。

## 结论与课程规模

**建议保持 125 课，不按学年数硬扩到 200 课。** 这套材料适合作为校内学习之外的数学原理课、提高课和轻奥入门。课标主干已有覆盖，本次找到的具体薄弱内容已补入相关课程。但不能据此称它是八册教材逐课时的替代品，也不能称成都所有 B 卷或全部奥数题型都已覆盖。

三至六年级是三、四、五、六四个学年，共八个学期。课数、知识点数和学校课时数是三种口径。一课可以包含几个相关概念、两次短课和多种应用；同一知识也需要反复操作、练习和复习。

例如，“分数的意义”包含单位“1”、分数单位、分数与除法、真分数、假分数和带分数；“倍不是多”还附有和倍、差倍、年龄差的画图选学。把这些都算作一个知识点会少算，把每道变式再算一个知识点又会无限增加。**不能用 125 这个数字证明够，也不能单凭它判断不够。**

当前安排：

| 学段 | 基础 | 提高选学 | 轻奥选学 | 合计 |
|---|---:|---:|---:|---:|
| 三、四年级 | 42 | 5 | 9 | 56 |
| 五、六年级 | 60 | 5 | 4 | 69 |
| 合计 | 102 | 10 | 13 | 125 |

“满十进一”“竖式的秘密”“0 的隐身术”及其课程页、配套材料、学习端视频已移除，首页和课程目录不再保留回顾入口。当前学习端有 49 课视频。旧课号不重新编号，避免改变其余课程地址。历史制作文件和审查记录保留，历史链接注明课程已移除，不再指向不存在的学习页。

## 依据与本次检查方式

1. [教育部《义务教育数学课程标准（2022年版）》](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220510531636118932.pdf)：核对第二、第三学段的内容要求、学业要求与相关教学提示，主要为印刷页 20–27、29–35、38–41、46–53。本次网页工具未能直接打开 PDF，使用此前保存的官方 PDF 及对应页面 OCR 复核，沿用前轮对关键原图的检查。课标没有把项目课程规定为固定的 125 或 200 课。
2. [温江区三上新教材培训记录](https://pcxx.wjjy.cn/newsInfo.aspx?pkId=15464)，2026-09-18：本次重新获取并读取学校原文，确认北师大版新教材、三上大数加减、认识图形及校园记录实践的教研方向。这不能代表全市八册版次已经逐页确认。
3. [国家教育平台 2023 年基础教育精品课传课目录](https://cdncs.ykt.cbern.com.cn/v0.1/static/competitive_activities/portal/html/xiaoxue.pdf)：本次读取北师大版三至六年级数学节点，作为旧版内容的交叉检查。它提供了含 0 乘法、密铺、观察范围等核查线索，**不是 2026 年新教材同步目录，也不是全部教材课时的完备清单**。
4. 实际课程文件：核对 125 份讲授稿与上轮终稿哈希，114 份未变，复用上轮逐课审查证据；另外 4 份仅把入口说明由“提高”改成“轻奥”，7 份在本次补充内容后重新检查。抽查重点包括删除后的算理承接、应用题方法、真实读图任务，以及教材场景中容易遗漏的空间与铺图问题。本次不是再把全部 125 课逐字、逐题重审一遍。

沿用的课标核查表将要求归纳为 **94 项**，其中三四年级 37 项、五六年级 57 项。这是项目的核查粒度，含概念、操作、应用和实践能力，不是教育部公布的知识点总数。此次重新检查这些条目的课程路径与内容承接，更新了加减互逆和三四年级媒体读图的落点；具体证据与复用范围见 [本次覆盖核查数据](../制作/课程范围核查/覆盖核查.json)。

## 主干是否有明显整块遗漏

| 内容范围 | 现有课程如何承接 | 判断 |
|---|---|---|
| 整数与位值 | 大数、里程表与加减、整数乘除、试商、商不变 | 主干具备；本次补含 0 乘法与连续跨零退位 |
| 运算与数量关系 | 混合运算、运算律、简算、倍数、数量关系列式、估算 | 主干具备；本次补归一归总与整数倒推 |
| 小数 | 一位小数到完整位值、性质、四则运算、循环、近似与取整 | 主干具备；一课内的基础与后续选学分开使用 |
| 因数、倍数和分数 | 奇偶质合、公因数公倍数、意义、性质、约分通分、四则与应用 | 主干具备，不把每个名称都另开一课 |
| 比、比例与百分数 | 比值、按比分配、比例、正比例、百分率、增减、折扣等 | 主干具备；正式反比例另列提高选学 |
| 字母与未知数 | 字母表示关系、等式性质、线段表示、列方程选学 | 基础要求与更系统的求解分开 |
| 平面图形 | 分类、角、平行垂直、周长面积、三角形性质、圆与扇形 | 主干具备；本次补密铺操作 |
| 立体图形 | 长正方体、展开图、表面积、体积容积、圆柱圆锥、切拼与排水 | 主干具备 |
| 空间与变换 | 不同方向观察、数对、方向距离、比例尺、平移旋转对称 | 主干具备；本次补挡板后的观察范围 |
| 统计与可能性 | 调查、统计表、条形折线扇形图、平均数、定性可能性 | 主干具备；三四年级真实媒体读图任务已补回本学段 |
| 量与实践 | 时间、年月日、长面积体积质量单位、测量、校园图、节水调查 | 有实际任务；任务完成效果仍须在学习中观察 |

因此，“缺一整块三至六年级基本数学内容”并不是现在的主要问题。更需要关注的是孩子能否把同一方法用于条件不同的问题，以及长课是否应分成两三次学习。

## 提高与轻奥够到什么程度

13 课轻奥是目录中的课数，不是全部拓展方法的数目。集合与容斥、两次植树有主题重合；基础课里也含独立标出的提高内容。

| 方法或主题 | 实际入口 |
|---|---|
| 和倍、差倍、年龄差 | 三上“倍不是多”的画图选学 |
| 和差、移多补少 | 五上“画线段，找数量关系” |
| 归一、归总 | 四上“先认清每个数在说什么” |
| 倒推还原 | 三上“混合运算与括号”、六上“连续变化与还原” |
| 有序搭配、组数、路线计数 | 三下“搭配” |
| 周期、间隔、植树 | 三下“周期”“植树”、五上“植树” |
| 重叠计数、容斥 | 三上“集合圈”、四上“容斥” |
| 假设替换、盈亏 | 四下“鸡兔同笼”及选学段 |
| 数字谜、条件排查 | 四上“数字谜” |
| 相遇、追及 | 四下“行程”；速度关系先在基础课学习 |
| 合理安排任务 | 四上“优化” |
| 平均数反求总量与合并 | 四下“平均数里藏着总数” |
| 称量决策、最坏情况 | 五下“找次品” |
| 数形规律、至少与保证 | 六上“数与形”、六下“鸽巢问题” |
| 工程、浓度、连续百分数变化 | 六上分数除法与百分数应用的提高段 |
| 图形割补、等积变化与立体切拼 | 面积系列、组合图形、六下“切开以后，什么变多了” |

**作为轻奥入门，这些内容已经足够形成一条学习路线。** 不继续默认加入复杂同余、数论证明、复杂计数或竞赛几何。今后是否增加某个专题，应看现有方法是否真的解释不了所选任务，而不是见到一个新的题型名称就开课。

作为 B 卷提高资源，当前已经有较广的覆盖；但还缺一套明确教辅或足够的成都实际试卷作为验收题库，无法核实“所有 B 卷题型”。本次决定先保留课程规模，补现有课程中的真实缺口；不把“覆盖主干”写成“每种考试题都保证见过”。
