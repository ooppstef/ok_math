# 视频生产说明

视频由 `工具/render_episode.py` 生成。改分镜 JSON，重跑一条命令，就能出新一集。

## 环境

- macOS
- Python 3.10+，Pillow
- ffmpeg
- 系统字体：Hiragino Sans GB、STHeiti Medium
- 系统中文配音：Tingting

检查：

```bash
python3 -c "import PIL; print(PIL.__version__)"
ffmpeg -version | head -1
say -v '?' | grep Tingting
```

## 生成

```bash
python3 工具/render_episode.py 工具/episodes/L01.json \
  --out 课程/三上/L01-满十进一/视频.mp4
```

输出：

- `视频.mp4`：1280×720，24fps，H.264 + AAC
- `视频.srt`：按场景切分的字幕

只预览某一幕：

```bash
python3 工具/render_episode.py 工具/episodes/L01.json \
  --out /tmp/preview.mp4 --preview 3 --preview-frame 4.0
```

## 分镜 JSON

```json
{
  "no": "01",
  "kicker": "为什么实验室 · 第 1 集",
  "scenes": [
    {
      "type": "title",
      "title": "满十进一",
      "subtitle": "为什么数到十，就要换一根柱子？",
      "narration": "如果我问你，九加一等于几……"
    }
  ]
}
```

- `no`：右上角期号。
- `kicker`：左上角小标题。
- `scenes`：按顺序播放，每幕时长由配音长度决定。
- `narration`：旁白。改旁白，节奏自动跟着变。

## 场景类型

| type | 用途 | 关键参数 |
|---|---|---|
| `title` | 片头 | `title`, `subtitle`, `foot` |
| `bullets` | 要点列表 | `heading`, `items`, `at`, `caption` |
| `sticks` | 小棒、捆、数位格 | `hundreds`, `tens`, `ones`, `merge`, `zones` |
| `place_value` | 数位卡片 | `digits`, `labels`, `values`, `note` |
| `column_add` | 竖式加法 | `a`, `b`, `result`, `highlight`, `notes` |
| `number_roll` | 数字滚动、进位 | `from`, `to`, `caption` |
| `grid` | 点阵、方格、旋转 | `rows`, `cols`, `kind`, `rotate`, `equation` |
| `challenge` | 挑战页 | `question`, `hint`, `digits` |
| `outro` | 片尾 | `text`, `sub` |

## 时间参数

用来对齐旁白，不填就用默认值。

- `at`：bullets 每条的出场时间
- `cap_at`：说明文字出现时间
- `eq_at`：等式出现时间
- `note_at`：结论出现时间
- `highlight_at` / `notes_at` / `result_at`：竖式
- `carry_at` / `carry_step`：数字滚动
- `line_at` / `hint_at` / `digits_at`：挑战页
- `ones_at` / `ones_step` / `tens_at` / `bundle_step`：小棒
- `band_at` / `merge_at` / `label_at`：捆小棒

## 配音

默认 Tingting，语速 165。换音色：

```bash
--voice "Eddy (中文（中国大陆）)"
```

换语速：

```bash
--rate 150
```

## 加一集

1. 写旁白。先写孩子听完能记住的一句话，再写 3–5 分钟口语稿。
2. 切成 6–10 幕，每幕只做一件事。
3. 选现有场景。不够再写新场景。
4. 先生成一版，听节奏，再填时间参数。
5. 最后一幕留一个孩子能动手做的问题，不给答案。
6. 检查旁白和画面是否对齐，重新生成。

一集控制在 2.5–5 分钟。

## 边界

- 只能做纸面动画，不能拍真人。
- 配音是系统 TTS，情绪有限。
- 适合讲清一个原理，不适合替代整节课。
- 需要更活泼，可以在 MP4 上二次剪辑，加片头、音效或真人出镜。
