# 视频生产说明

视频由 `工具/render_episode.py` 生成。旁白、分幕音轨和画面分别保存；更换配音后，按新音轨长度重新渲染画面和字幕。

《竖式的秘密》的进位演示已制作成 [60 秒无声样片](../制作/三上-L02-竖式的秘密/样片/进位演示-无声.mp4)。本版用于检查教学动画，正式配音等待用户提供音色 ID；不会作为课程成片出现在首页。

## 环境

- macOS
- Python 3.10+，Pillow
- ffmpeg
- 系统字体：Hiragino Sans GB、STHeiti Medium
- 系统中文配音 Tingting 仅用于本地临时配音；无声预览与导入配音无需它

检查：

```bash
python3 -c "import PIL; print(PIL.__version__)"
ffmpeg -version | head -1
say -v '?' | grep Tingting
```

## 生成

```bash
python3 工具/render_episode.py 工具/episodes/L01.json \
  --out 课程/三上/L01-满十进一/视频.mp4
```

输出：

- `视频.mp4`：1280×720，24fps，H.264 + AAC
- `视频.srt`：按场景切分的字幕
- `视频.vtt`：网页字幕
- `视频.timeline.json`：实际分幕起止、旁白及配音来源类型

只预览某一幕：

```bash
python3 工具/render_episode.py 工具/episodes/L01.json \
  --out /tmp/preview.mp4 --preview 3 --preview-frame 4.0
```

## 分镜 JSON

```json
{
  "no": "01",
  "kicker": "为什么实验室 · 第 1 集",
  "scenes": [
    {
      "type": "title",
      "title": "满十进一",
      "subtitle": "为什么数到十，就要换一根柱子？",
      "narration": "如果我问你，九加一等于几……"
    }
  ]
}
```

- `no`：右上角期号。
- `kicker`：左上角小标题。
- `scenes`：按顺序播放，每幕时长由配音长度决定。
- `narration`：旁白。改旁白，节奏自动跟着变。

## 场景类型

| type | 用途 | 关键参数 |
|---|---|---|
| `title` | 片头 | `title`, `subtitle`, `foot` |
| `bullets` | 要点列表 | `heading`, `items`, `at`, `caption` |
| `sticks` | 小棒、捆、数位格 | `hundreds`, `tens`, `ones`, `merge`, `zones` |
| `place_value` | 数位卡片 | `digits`, `labels`, `values`, `note` |
| `column_add` | 竖式加法 | `a`, `b`, `result`, `highlight`, `notes` |
| `number_roll` | 数字滚动、进位 | `from`, `to`, `caption` |
| `grid` | 点阵、方格、旋转 | `rows`, `cols`, `kind`, `rotate`, `equation` |
| `challenge` | 挑战页 | `question`, `hint`, `digits` |
| `outro` | 片尾 | `text`, `sub` |
| `regroup_add` | 三上 02 的 38＋47 进位演示 | `stage`, `duration`, `equation`；此场景固定演示 38＋47 |

## 时间参数

用来对齐旁白，不填就用默认值。

- `at`：bullets 每条的出场时间
- `cap_at`：说明文字出现时间
- `eq_at`：等式出现时间
- `note_at`：结论出现时间
- `highlight_at` / `notes_at` / `result_at`：竖式
- `carry_at` / `carry_step`：数字滚动
- `line_at` / `hint_at` / `digits_at`：挑战页
- `ones_at` / `ones_step` / `tens_at` / `bundle_step`：小棒
- `band_at` / `merge_at` / `label_at`：捆小棒

## 先做画面，再换配音

当前样片先按预计时长制作，字幕可供无声查看：

```bash
python3 工具/render_episode.py 工具/episodes/三上-L02-进位样片.json \
  --silent --burn-captions \
  --out 制作/三上-L02-竖式的秘密/样片/进位演示-无声.mp4
```

每幕有稳定的 `id`、口播 `narration` 和无声预览时长 `duration`。进位样片的动作按该幕实际时长伸缩；旧场景的 `*_at` 仍是固定秒数，旧课换配音时需要逐项重新核对。

`--burn-captions` 将字幕合成到导出画面；不加此参数可导出不带字幕的画面，独立 SRT/VTT 仍会保留。

### 复用 nba_biz 的豆包配音

本项目的 `工具/prepare_narration.py` 调用相邻 `nba_biz/scripts/tts.py`，复用其接口及凭证读取。不会修改 nba_biz，不复制凭证，也不使用默认的篮球解说语气。这里明确指定自然、温和的课堂讲解语气，保留原始语速和音高。

先导出旁白，不读凭证、不请求接口：

```bash
python3 工具/prepare_narration.py 工具/episodes/三上-L02-进位样片.json \
  --out-dir 制作/三上-L02-竖式的秘密/样片/旁白
```

用户提供的 ID 应是豆包的 `speaker` / 音色 ID。如果提供的是已生成音频的资源 ID，需要先取得对应音频，再处理对齐，不能直接当作音色 ID。

确认音色 ID 后，把下方占位文字替换为实际值，才执行实际配音：

```bash
python3 工具/prepare_narration.py 工具/episodes/三上-L02-进位样片.json \
  --out-dir 制作/三上-L02-竖式的秘密/样片/配音-v1 \
  --voice-id '实际音色ID' --generate

python3 工具/render_episode.py 工具/episodes/三上-L02-进位样片.json \
  --audio-dir 制作/三上-L02-竖式的秘密/样片/配音-v1 --burn-captions \
  --out 制作/三上-L02-竖式的秘密/样片/进位演示-配音版.mp4
```

每次换音色使用新的配音目录。全部片段成功后才写 `manifest.json`，渲染前校对分镜 ID 和旁白全文，防止旧稿音频混入。音轨保持原速，画面跟随音轨时长，句末另留短暂停顿。当前按完整短句分幕，字幕覆盖这段真实音频，不按字数猜时间。最终仍需试听自然度、数学读音和相邻段音色是否一致，并检查动画动作与具体词句的对应。

### 系统临时配音

旧命令未指定 `--silent` 或 `--audio-dir` 时仍用 Tingting，语速 165。换音色：

```bash
--voice "Eddy (中文（中国大陆）)"
```

换语速：

```bash
--rate 150
```

## 制作一段原理短片

1. 先确认动画要解释哪一步，记录什么变、什么不变。分镜逐镜对照讲授稿。
2. 为这一步选对象和动作。当前通用场景不能实现的连续切拼、等式同步或刚性旋转，需要先补相应动画实现；有分镜不代表已有可渲染 JSON。
3. 写自然的短句旁白，公式和单位保留在画面。不限定每集同样幕数或时长。
4. 先做关键动作样片，检查数量、长度、面积、单位和对象连续性。
5. 暂停题先留出思考时间，再演示答案。接入正式声音后，按音轨重排动作和字幕。
6. 看完整连续视频、听完整音频，再标记成片可用。

当前完整标准见[每课标准流程](02-每课标准流程.md)，逐课安排见[27 号复核](27-数学原理全量优化与复核.md)。优先制作进位与拆包、小数乘法、等式同步、分数除法、多边形切拼、圆与圆柱切拼等短片。

原理图由 `python3 工具/生成原理图.py` 生成，保存在 `assets/原理图/`。它们给出静态讲解和几何参照，不能代替连续动画的实现与审片。

## 边界

- 只能做纸面动画，不能拍真人。
- 自然声音需要实际试听；本次只完成无声样片和 nba_biz 配音接入，未生成或验收正式声音。
- 适合讲清一个原理，不适合替代整节课。
- 需要更活泼，可以在 MP4 上二次剪辑，加片头、音效或真人出镜。
