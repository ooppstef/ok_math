# 三至六年级 B 卷课程审查

审查日期：2026 年 10 月 20 日。部分 P1 勘误已在同日晚些时候修正；后续处理状态见 `12-课程审查清单.html`。以当前课稿为准。对象：本项目现有方案、48 课地图、B 卷对照表、71 点覆盖表、入学诊断及第 1–4 课的讲授稿、动手单、分镜和已生成字幕。

**结论：现有方案尚不能满足三至六年级 B 卷课程的目标。** 主要问题是五、六年级主干缺失，部分三、四年级题型只有课次链接，原理实验与独立解题之间缺少明确教学步骤，已有样课还有需要先修正的数学表述和题目条件。

“动手理解—解释原理—应用迁移”的方向可以保留。扩展时应先补齐知识与方法，再确定课数和课时。

**本次如何理解 B 卷。** 按用户确认，范围为小学三至六年级。未指定出版社、册次和试卷，暂以课内提高、综合变式和常见基础培优为审查范围。不同材料的 B 卷定位不能混用：同步教辅的提优 B 卷按单元编排，奥数教程另有竞赛训练范围。本报告列出完整的本项目题型核对和扩展清单，但不把它称为所有出版社 B 卷的穷尽目录。[同步提优卷编排示例](https://ww.yuntaigo.com/book.action?recordid=b2FhaG9ubGM5Nzg3NTY1Njk2MDE1)、[华东师大出版社的教辅分类](https://jiaofu.ecnupress.com.cn/)。

**二 三至六年级需要补齐或深化的内容**

下面是对本项目的课程设计建议，不是照搬某一本教材的目录，也不要求所有学校按同一学期教学。五、六年级的分数、比、百分数、方程、圆、体积等确有课内教学基础；教育部公开的人教版课程条目可用于交叉确认，但该材料是历史课程名单，不能当作 2026 年完整新教材目录。[教育部课程条目，PDF 第 11–18 页](https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/A06/202203/W020220318610109798820.pdf)。

| 编号 | 内容与 B 卷要求 | 当前证据 | 应补的学习目标 |
|---|---|---|---|
| G01 | 整数加减乘除的算理、逆运算、混合运算、简便计算 | 前四课有部分成稿，后续有地图 | 连续进退位、乘除竖式含 0、验算、补偿与拆分、括号改变关系；原理与算法连接 |
| G02 | 位值、组数、数位错误、近似数范围 | 有位值样课与估算规划 | 除求近似数外，反推原数最大最小；明确 0 能否首位、数字能否重复 |
| G03 | 数字与图形规律、等差排列、数表、配对求和 | 总方案提到数列，地图只有周期主课 | 分清重复与递增；解释第几项、项数和总和，避免由少数例子断言唯一规律 |
| G04 | 奇偶、整除、质数合数、因数倍数、公因数公倍数 | L03 仅有因数配对 | 建立整除与余数关系，解决最大等份分组、最小共同周期；区分质数与奇数 |
| G05 | 小数乘除、混合运算、商与积的近似、循环小数认识 | 地图到小数意义、移动与加减补充 | 解释乘小于 1 的数、除以小于 1 的数；判断结果大小；将近似值用于具体约束 |
| G06 | 分数意义、分数单位、真分数假分数、带分数、分数与除法 | 三上 10 仅规划初步分数 | 同一整体与不同整体、一个物体与一组物体作整体；数轴表示分数 |
| G07 | 等值分数、约分通分、分数比较、分小互化 | 缺系统安排 | 说明分子分母为什么同步变化；比较要有依据；通分前掌握公倍数 |
| G08 | 分数四则、混合运算、倒数、分数简便计算 | 只有同分母加减补充点 | 统一单位解释加减，面积/倍数模型解释乘法，逆运算解释除法 |
| G09 | 分数应用、单位“1”、已知部分求整体、连续变化 | 缺系统安排 | 同时写清比较对象、比较标准和对应分率；处理前后整体变化，不能见分数就乘 |
| G10 | 百分数、百分率、增减幅度、连续增减、折扣、利润、税率利率 | 四下市场项目提到利润折扣，缺前置课程 | 区分成本、售价和原价作基准；分清百分比与百分点；学校情境中的利税计算 |
| G11 | 比、化简比、按比分配、比的变化 | 只有“倍”和正比雏形 | 从一份量到份数比，统一比的基准，识别总量不变、差不变及一方不变 |
| G12 | 比例、正反比例、比例尺、缩放关系 | 缺系统安排 | 看商不变或积不变；区分线性尺寸、面积、体积的缩放倍率 |
| G13 | 等量代换、用字母表示关系、等式性质、方程与应用 | 只有数字谜中的字母 | 字母表示未知数和一般关系；列等量关系、解方程、代回检验，不把猜数字当作代数教学 |
| G14 | 和差、和倍、差倍、年龄、归一归总、盈亏、还原 | 多项挤在倍、乘法、鸡兔课或挑战卡 | 各自建立线段图/表格，明确不变量；练习同情境不同条件和逆向问题 |
| G15 | 行程基础、相遇追及、错时出发、过桥、平均速度 | 全部压在四下 11 及一张挑战卡 | 先掌握速度单位与路程时间表，再看距离怎样变化；平均速度单独计算总路程和总时间 |
| G16 | 工作效率、工作总量、合作完成、分段合作 | 缺系统安排 | 依赖分数和单位“1”，先用有具体总量的题建立效率，再过渡到总量设 1 |
| G17 | 购物方案、分段计费、租车购票、预算和最优选择 | 市场项目与优化课有笼统目标 | 区分起步部分与超出部分；枚举满足条件的方案并说明为什么最优 |
| G18 | 长度质量时间、面积体积容积、复合单位 | 长度时间与面积有地图；体积容积缺失 | 单位大小、进率及数量级检查；特别处理平方/立方进率，避免统一按 10 换算 |
| G19 | 周长、剪拼边界、等周与靠墙最值 | 有地图 | 对比角落缺口与边中缺口；在明确形状及约束下讨论最值，不能把长方形结论推广到所有形状 |
| G20 | 三角形、平行四边形、梯形面积，组合与等积变形 | 只有长方形面积、三角形边角与稳定性 | 建立底与高，再做割补、添辅助线、等底等高、面积比；三角形内角和不能代替面积教学 |
| G21 | 圆周长面积、半圆、圆环、扇形及阴影组合 | 缺失 | 区分弧与边界、半径与直径；从整体减去部分或等积转化求阴影面积 |
| G22 | 长方体正方体、表面积、体积、容积、展开图 | 缺失 | 从铺面和堆单位方块区分面积与体积；处理无盖、拼接、切割和展开 |
| G23 | 圆柱圆锥、组合立体、排水与等积变形 | 缺失 | 区分侧面积与表面积；同底等高的条件；用体积不变分析液面和形状变化 |
| G24 | 角、平行垂直、三角形分类、钟面角 | 有地图，钟面题提前到三上 | 先确认量角、角度加减及两针都在运动；早期探索不算正式掌握 |
| G25 | 方向、数对、方向与距离、路线和地图 | 三下有八方向；数对与距离定点缺失 | 建立坐标顺序、参照方向、角度和距离，再进入比例尺地图 |
| G26 | 对称平移旋转、观察物体、方块计数与视图 | 图形运动有地图，观察物体只有项目名 | 旋转需中心、方向和角度；由视图推最少最多方块；独立验收空间表示 |
| G27 | 分类计数、加乘原理、排列组合、重复计数、图形计数 | 有搭配与容斥规划，L03 有局部计数 | 明确顺序、可重复性、分类标准；区分分步相乘和分类相加；从枚举到一般方法 |
| G28 | 植树间隔、队列方阵、周期、日期时间 | 有地图与 L04 局部余数题 | 点段边界、封闭与不封闭、实心与空心、端点是否计入、余数为 0、跨日跨月 |
| G29 | 逻辑、假设、反证、抽屉、数阵、称重找次品 | 前四类多数只有挑战卡名；找次品缺失 | 给出约束表、推理步骤；区分“可能”与“保证”；称重题写明次品轻重是否已知 |
| G30 | 统计表、单复式条形图、折线图、扇形图、平均数 | 有统计表和平均数地图，后两种图缺失 | 图表选择、读图补图、总量与比例、不同人数的合并平均；用数据解释结论 |
| G31 | 可能性、随机试验、公平游戏、最坏情况 | B 表挂名，无相应课程活动 | 区分可能性大小与一次结果；等可能条件下比较数量；区分概率判断和保证发生 |
| G32 | 负数的生活意义、数轴、基准和相反意义的量 | 缺失 | 温差、收支、海拔、零点参照；不自动扩张到初中的负数四则 |
| G33 | 综合信息题、开放题、条件充分性、检验与表达 | 有末尾市场项目，无系统验收 | 筛选多余信息、指出缺失条件、比较多种方案、说明答案为何合理 |

常见培优目录还会单列整数整除、余数、等积变形、环形行程、逻辑、抽屉等方法。这支持把它们作为独立学习目标核对，不能仅靠“运算结构”或“空间与变换”的大标签代替。[《奥数教程》五年级第八版目录](https://yuntaigo.com/book.action?recordid=bm56emFrbGM5Nzg3NTc2MDQ5NjU3)。

**扩展题型需要单独分级。** 流水行船、环形跑道、钟表追及、多次相遇、浓度混合、牛吃草、数位计数与页码、余数综合、复杂数阵、染色与策略游戏，可在核心知识建立后按所用 B 卷选配。循环小数化分数、复杂裂项、复杂几何面积模型、较深数论不应默认全部列为普通同步提高课的必修。现有一笔画也应标成选学；孩子的目标试卷决定这些项目是否需要。

**五 从理解原理到解题需要补的教学过程**

每个要覆盖的 B 卷模型，都应有以下证据。可以分散到多次短练习，不要求塞进一次课。

| 环节 | 需要留下的教学内容 | 以差倍问题为例 |
|---|---|---|
| 先修 | 孩子进入该模型前应能做什么 | 会把某个量当一份，会读倍数，会求每份量 |
| 原型 | 用实物或图解释数量关系 | 甲 4 段、乙 1 段，多出的 3 段对应 12 |
| 解题过程 | 从题干选量、标标准、建关系、计算、检验 | 12÷(4−1)=4；两量 16 和 4，再核对差及倍数 |
| 同结构迁移 | 换情境、换数值但保留关系 | 纸条、人数、钱数中的差与倍 |
| 辨别 | 相似文字却要换方法 | 差 12 与和 12；是 4 倍与多 4；比较标准换成另一个量 |
| 逆向与组合 | 改变未知量或增加一步 | 已知两量求差或倍；给出转移前后的关系 |
| 独立验收 | 不标题型、不给分步提示 | 混排一道和倍一道差倍，要求先说明用哪个条件及为什么 |
| 延后复测 | 隔几天换表述再做 | 检查是否能独立识别，记录是否依赖家长提示 |

目前的四个问题“看到什么、为什么、如何证明、改变条件怎样”适合保留。需要补充的是明确的中间教学和检验材料。C 层可选，也不能让必须掌握的核心模型只出现在允许跳过的挑战里。

**六 课程顺序和课时的调整建议**

1. 先建立三至六年级总表。每项写清知识前提、原理、模型、代表题、变式边界和验收方式。去掉“根只有 48 个”这类无法验收的绝对表述。
2. 修正已成稿四课，再以它们验证新的课包结构。位值、阵列、除法实物模型仍可使用；补上上文勘误和缺失的运算桥梁。
3. 三、四年级优先补线段图、等量关系、有序枚举、规律与求和，并将和差、和倍、差倍、归一归总等模型分开验收。掌握已足够的位值、交换律可以通过诊断缩短。
4. 五年级建立整数性质、小数乘除、等量关系与方程、分数单位与通分、平面面积及长方体正方体的主干。与三、四年级内容相互回访。
5. 六年级建立分数乘除与单位“1”、百分数、比与比例、圆及圆柱圆锥，串联效率、行程、商业情境和综合信息题。具体先后服从先修关系与学生学校进度。
6. 项目周写出真实任务、材料、问题、答案要点和验收题；明确安排在何时。只有项目名称不计为教学完成。
7. 按目标决定单元长度。倍数模型、计数、行程和优化可以有共同开场实验，但应分别保留模型学习与练习时间。当前证据不足以认定每学期 12 次课即可覆盖全部要求。

例如需要明确的先修链包括：

- 等份与倍数 → 线段图及和差倍 → 归一归总 → 比与比例。
- 因数倍数 → 等值分数与通分 → 分数四则 → 单位“1”应用 → 百分数与效率。
- 单位面积 → 底高与割补 → 多边形面积 → 圆与组合面积。
- 单位体积 → 长方体正方体 → 圆柱圆锥 → 等积变化和排水。
- 有序枚举 → 分类相加与分步相乘 → 去重计数 → 容斥与保证问题。
