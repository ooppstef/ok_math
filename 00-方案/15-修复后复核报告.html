审查日期：2026 年 10 月 20 日。基线：6acc78b，包含 829b799 的课程修复及后续 README 整理。对照 14 号报告检查本次差异及受影响课稿；没有把尚未成稿的全部课程重新判一遍。

结论：多项数学勘误已经修复，但本轮还不能全部关闭。 主要遗留是修正文句没有同步到挑战单和纠错表，另有新增的成数表述和近似数题目条件问题。课程覆盖的缺项现在大多已明确标为待补，这比上一版准确；“待补已登记”仍不等于教学已完成。

按上一轮 R01–R10 的问题范围，本轮可关闭 4 项，6 项部分完成。新增例题的计算结果均核对正确；原有 96 课地图仍对应 8 节讲授稿。本报告区分确定的错误、已修项目和后续课程建设，不把它们混成同一种问题。

一 仍需修改的具体问题

编号 优先级 位置与发现 影响及修正方法
F01 P1 五六年级地图第 71 行新增“是去年的八成，和比去年少二成，不是同一句话”，作为成数边界说明容易被读成数量关系不同。 两种说法在同一比较标准下等价：今年量=去年量×0.8=去年量×(1−0.2)。去年 100，两个说法都得到今年 80。应直接讲“说法不同，数量关系相同”；真正应对比的是“是去年的八成”和“比去年少八成”，后者为去年的 20%。
F02 P2 数对讲授稿第 190 行仍把“移动时只改一个数”放在错误栏。 点 (3,4) 只向右移 2 格，正确结果就是 (5,4)，只改一个数。家长按纠错表会否定正确解法。改为“两方向都有移动，却只改了一个数”；单方向移动的另一坐标保持不变。此项上轮已指出，本轮仅改了课时。
F03 P2 小数乘法挑战单第 56 行仍写“小数位数是两个因数小数位数的和”。教师稿已经说明化简后位数可能减少，但学生单未同步。 同一张挑战单中 0.25×8=2、0.125×0.8=0.1 都说明规范结果的位数不一定等于位数和。改为“按两个因数的小数位数和给整数积点小数点，不足补 0，再化简；化简后的位数可能减少”。
F04 P2 循环小数讲授稿第 217–218 行仍把“除不尽就是循环小数”笼统判错，且循环起点接法没有同步；挑战单第 53 行仍说“从第一个重复的余数开始”。 本课两个有限小数相除、除数非零，若“除不尽”指小数展开不终止，商确实会循环；若要纠正的是“不能整除就一定循环”，应把题干写清，1÷8 即反例。循环起点统一说明余数是补 0 前还是运算后记录，并用“余数—产生的下一位商”表找循环，不把余数所在列的商当起点。
F05 P2 小数乘法挑战单第 19 行新增题只问“大约多少钱”；答案第 41 行却要求“看题目要求保留到哪一位”，题目实际上未给精度。讲授稿加餐也直接给约 20.6 元。 20.64 保留一位小数为 20.6，保留整数为 21，两者都可有合理用途。若验收积的近似数，补“得数保留一位小数”；若训练估算，改成开放题，要求说明精度和用途，并按理由判断，不能只接受一个数值。
F06 P2 新 B 卷表第 16 行仍写“除以小于 1 的数会变大”，地图六上 02 已补正被除数与正除数范围，题型表没有同步。 0÷0.5=0，不会变大；除数为 0 时无意义。统一为“正被除数除以大于 0、小于 1 的数，商大于被除数”。

对 F01 的审查说明：上一轮报告把这两个等价说法写在“区分”下面，措辞不够准确，可能造成误读。 本轮已更正 14 号报告的建议：应建立两种说法的等价关系，再与“少八成”对比。本次没有直接修改课程地图。

F02、F03、F04、F06 的旧表述也存在于相应 HTML 阅读版，所以下次应先修 Markdown，再生成阅读版；仅改地图或审查清单不够。

三 已改进但还不能当作教学完成的部分

小数除法仍缺“变成整数除数以后怎样除”的教学。 L02 第 67–79 行从 0.48÷0.6 直接到 48÷60=0.8 或 4.8÷6=0.8，没有解释不足商 1 时写 0、商的小数点、补 0 继续除。新增取整题解决了实际问题的出口，没有补上这个中间步骤。建议用 4.8÷6、0.48÷6、4.08÷4 三个短例连接计数单位与竖式，再让孩子独立做 5.04÷4=1.26。

加餐应区分可跳过的拓展与需要补齐的核心内容。 L01 第 221 行和 L02 第 195 行把近似数、简算、取整标为可选；它们同时属于覆盖目标。可以允许已掌握的孩子经检测后跳过，但未掌握者需要有固定的短课和验收。L01、L02 新增例题数值均正确，不能再说这些内容完全没有；准确状态应是“已有示例，待独立验收或待补完整教学”。

前测还缺分流规则。 README 第 70–78 行包含分数加法、按比分配、体积，它们不是五上小数乘法课的共同先修。刚进入五年级的孩子未学过这些内容，不能因此被判定不能开始小数课。需要按拟学模块选题，并分别记录“未学过”与“学过但困难”；例如不会 1/2+1/3，应定位分数单位和通分，而不是要求在小数乘法前补完整个五下。

审查状态应记录工作是否完成。 审查清单第 58–61 行给 R03、R04、R09、R10 全部打勾，旁边却仍写待补、待写、待排、待做。建议将“确认处理方向”与“完成教学验收”分列；本轮表格给出的“部分完成”更适合继续跟踪。
