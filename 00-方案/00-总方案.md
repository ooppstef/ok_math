# 总方案

## 目标

三上到四下，48 节核心课。每节课讲清一个规则为什么成立，再用 B 卷题检验。

- 孩子能用自己的话解释规则，不靠背步骤。
- 遇到没见过的题，能画图、列表、举例，找到关系。
- 每节课有 5–15 分钟动手时间，材料在家里找得到。
- 轻奥只取同一个原理的极端情况，不另开一套技巧课。

## B 卷考什么

多数 B 卷题考三件事：

1. 关系：谁和谁成比例，谁不变。
2. 表示：能不能把文字换成图、表、算式。
3. 迁移：换一个情境，还能不能认出同一个结构。

所以课程按原理组织，B 卷题型放在“应用出口”的位置。孩子先懂原理，再做题。

## 课程结构

8 条原理线：

| 线索 | 内容 |
|---|---|
| 位值 | 数是打包出来的，位置决定大小 |
| 等价与守恒 | 同一个量可以换一种样子 |
| 运算结构 | 加减乘除之间的关系 |
| 关系与模型 | 份、倍、和差、行程、鸡兔 |
| 度量 | 周长、面积、单位、角度 |
| 空间与变换 | 拆分、拼补、平移、旋转、对称 |
| 规律与推理 | 周期、数列、假设、枚举 |
| 数据与不确定 | 统计表、平均数、可能性 |

4 个学期：

| 学期 | 12 课的主线 | 阶段目标 |
|---|---|---|
| 三上 | 位值、竖式、乘法、除法、倍、周长、分数 | 能用“单位”和“阵列”解释运算 |
| 三下 | 面积、等周、小数、年月日、搭配、周期、植树 | 能区分周长与面积，用“份”解应用题 |
| 四上 | 大数、进制、角度、积商规律、优化、容斥 | 能看变化中的不变量，能做多步推理 |
| 四下 | 运算律、小数性质、三角形、统计、鸡兔、行程 | 能说明“为什么一定”，能完成一次建模 |

48 课的逐课安排见 `01-48课知识地图.html`。

## 每课怎么上

70 分钟，五个环节：

| 时间 | 环节 | 做什么 |
|---|---|---|
| 0–5 | 开场 | 复习上一课，抛一个错误说法或赌局 |
| 5–20 | 动手 | 先猜，再做，记录，找冲突 |
| 20–30 | 视频 | 看 3–5 分钟原理视频，允许暂停 |
| 30–45 | 对话 | 四个问题，把实验翻译成一句话 |
| 45–65 | 挑战 | A 基础、B 变式、C 轻奥 |
| 65–75 | 复述 | 孩子讲，家长听，写原理卡 |

详细话术见 `02-每课标准流程.html`。

## 家长做什么

你不需要会讲奥数。做三件事：

- 提问：把“懂了吗”换成“举个例子”。
- 记录：把孩子的话记下来，不急着纠正。
- 旁听：孩子复述时，不插嘴，不代答。

四个常用问题：

1. 你看到了什么？
2. 你猜为什么？
3. 你怎么证明？
4. 如果改一个条件，会怎样？

孩子说“不会”时，按顺序给三级台阶：回到实物，回到图，回到更小的数。三级之后还不会，记下来，下周再看。

## 评估

每月打一次分，1–5 分，只看趋势。

| 维度 | 看什么 |
|---|---|
| 解释力 | 能不能用自己的话讲清为什么 |
| 建模力 | 遇到新题，会不会主动画图或列表 |
| 动手力 | 能不能设计一个小实验验证猜想 |
| 坚持力 | 卡住时，能不能换一种方法再试 |

每课写一张原理卡：

```
【课题】
【本课要点】
【一张图】
【一个反例或还没想通的问题】
```

每月让孩子挑一个原理，讲 10 分钟给家人听。

## 边界

- 不替代学校课堂。计算熟练度仍然靠课内练习。
- 不要求提前学完教材。没学到的内容，先用实物建立经验，不要求熟练。
- 不刷整套 B 卷。每课只做 1–2 道对应题。
- 孩子明显抗拒时，停一周。先恢复关系，再恢复课程。

## 教材说明

默认按人教版编排。北师大版、苏教版可以按知识点对应调整顺序，原理线不变。

课内一些单元没有单独占课，例如四上条形统计图、四下观察物体、小数加减法。它们分别并入统计课、图形课和小数课，项目周补上。

## 覆盖

三、四年级 71 个知识点，51 个有专门一课，16 个在主课里加 10–15 分钟，2 个交给课内练习，2 个项目周。逐点见 `06-覆盖核对.html`。

只核对了三、四年级。一、二年级的先修没有逐点列，诊断发现漏洞再补。
