这套课怎么想

三到六年级的 B 卷题，难点常在“从哪下手”。同一个知识点，换个问法，孩子就认不出来。

课程把教材知识点归到 8 条原理线索：

位值、等价与守恒、运算结构、关系模型、度量、空间变换、规律推理、数据与不确定。

每课围绕一个主要关系展开；较长的扩展拆成另一次短课。先说明图中怎样变化、什么不变，再对应到算式，用练习和变式检查理解。

范围是校内提优和少量轻奥，不接竞赛。竞赛专属内容放挑战卡或项目周，不占正课。

教材版本

项目采用北师大版新教材作为主线方向，三上书目身份和成都当前教研证据见 19 号教材版本映射。原有文件夹沿用较早的编排：小数乘法与方程放在五上，分数乘除放在六上。学习时应按实际知识点和前置能力选课，不据文件夹判断学校教学进度。

本项目不绑定具体学校，也不再以提供学校名称作为继续制作的前提。四至六年级先按课程标准学段和已学内容安排；其新版逐册目录确认后，再更新同步顺序。需要时用下面的模块准入检查。

课程怎么用

每课先看视频或读讲解，再做例题和挑战；不设统一 75 分钟，也不要求家长准备实验材料。按孩子的状态分段使用，一次只推进一个知识点。

怎么开始

  1. 做一次 00-方案/05-入学诊断.html。8 个问题，记录原话，不打分。
  2. 选一课，先看视频或读讲解。
  3. 选起点：三年级从三上 L01 开始；五、六年级先做下面的模块准入检查，再决定从哪课开始。
  4. 每周推进一到两课；一次只完成一个知识点也可以。

开始前的准入检查

先确认要学的模块，不做一张覆盖所有年级的统测。每项记三种状态：没学过、学过但卡住、能独立做。没学过不是失败，补对应前置即可。

准备学的模块 只查这些前置 没学过时
五上 01 小数乘法 整数乘法、十进位值、小数意义（0.1 是 1/10） 三上 01–03 的位值、竖式与进位；三下 06 的小数意义
五上 02 小数除法 整数除法竖式、商不变、小数意义 三下 01 的除法竖式；五上 02 的商不变段
五下 09 分数意义 平均分、几分之一 三上 10；不以尚未学过的通分作入口
五下 10 分数性质 分数单位、因数和公因数 五下 09、五下 01–03
五下 11 分数加减 同分母加减、通分 三上 10 的加减短课、五下 10；折线图短课可独立学
六上 01–02 分数乘除 分数意义、真假分数、带分数互化 五下 09–10；工程短课还需要分数加减
六上 03–04 比 除法、分数意义 先学六上 03，再学按比分配，不把“比”本身作为 03 的先修
五下 06 长方体认识 长方形、正方形及长度单位 三上 08–09、三下 03–05
五下 07–08 表面积与体积 面积、长方体的面棱顶点、单位换算 五下 06；体积单位在 08 中学习

每一项记四件事：算对没有、会不会画图、能不能解释、需要多少提示。能独立做就直接进课；学过但卡住就补对应课；没学过先补前置，不要用分数、比或体积去卡小数乘法的入口。

本地阅读与构建

直接打开 index.html 就能读。重新生成 HTML：

npm install
npm run build

需要 Node 18 以上。构建脚本在 工具/build_html.js。

重渲染已有视频：

python3 工具/render_episode.py 工具/episodes/L01.json --out 课程/三上/L01-满十进一/视频.mp4

旧视频命令需要 Python 3、Pillow、ffmpeg 和 macOS 的 say。Tingting 仅用于临时配音。当前已接入 nba_biz 配音流程，正式声音等待用户的音色 ID；换声音后按新音轨重新安排画面和字幕，见视频生产说明。

重新生成原理图：python3 工具/生成原理图.py。分镜中的新切拼、旋转等动作还需逐课实现并审查，不能直接靠旧场景自动生成。
