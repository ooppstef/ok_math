小学数学 · 三至六年级原理与提高课

三至六年级的数学讲解、例题与练习。

课程目录

一套面向小学三至六年级的数学课程，包含 128 课图文讲解、例题、练习和答案，其中 51 课配有数学原理动画。适合孩子学习，也方便家长陪学、教师选用。

课程从具体问题出发，用小棒、方格、线段图和图形变化解释数学：竖式里为什么要进位，分数怎样表示一部分，图形剪开再拼好为什么面积不变。理解这些关系后，再用算式解决问题，并通过提高题练习不同的用法。

下载项目后，用浏览器打开根目录的 index.html，即可进入课程。也可以打开 课程目录 选课。

课程内容

课程涵盖数与运算、数量关系、图形与几何、统计与可能性，以及测量、调查等实践活动。

目录分为四组：

  • 三、四年级基础：整数运算、分数与小数初步、长度与面积、方向、统计等。
  • 三、四年级提高选学：搭配、周期、植树、鸡兔同笼、行程等。
  • 五、六年级基础：小数与分数运算、比与百分数、等量关系、平面图形与立体图形、统计与可能性等。
  • 五、六年级提高选学：找次品、数与形、切拼、综合应用等。

每课开头列出需要先掌握的知识。正文包含原理讲解、例题、练习及答案，部分课程另附可打印的动手单和挑战单。有动画的课程会标出“▶ 视频”；动画用来展示分组、拆分、移动、剪拼等变化过程。

课程面向成都地区的日常学习与提高需求，按知识关系组织，适合作为校内学习的补充。可结合孩子的课本进度选课，提高与衔接内容按需学习。

怎样学习

  1. 选一课，先看看课首的“先会”，确认相关基础已经掌握。
  2. 阅读讲解；遇到动画或动手任务，跟着画一画、摆一摆、算一算。
  3. 独立完成练习，再核对答案和解法。
  4. 试着说清楚每一步为什么这样做，再尝试提高题。

测量、画图等活动需要纸笔、尺子、方格纸等简单材料，具体要求见课程正文或动手单。内容较多的课可以分几次学习。

本地使用与修改

阅读课程直接打开 HTML 文件即可，无需安装依赖或启动服务。

课程的 Markdown 文件是内容源文件，HTML 文件是阅读页面。修改内容后，在 Node.js 环境中生成页面：

npm install
npm run build
