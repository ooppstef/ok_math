# 小学数学 · 三到六年级 B 卷原理课

一套给家长用的课程包：96 节课，从三上到六下。每节课只讲一个“为什么”，配一个动手实验、一份讲稿和三层挑战。B 卷题用来检验原理，不用来刷题型。

当前进度：96 课地图完成；24 课成稿（三上 1–4、五上 1–12、五下 1–8）；2 段视频。五、六年级先审课稿，再做视频。

当前可教范围：24 课有讲授稿、学生任务和答案；其余 72 课只有规划。没有教学段、学生任务、答案和独立验收题的课，不按“已覆盖”使用。

## 这套课怎么想

三到六年级的 B 卷题，难点常在“从哪下手”。同一个知识点，换个问法，孩子就认不出来。

课程把教材知识点归到 8 条原理线索：

位值、等价与守恒、运算结构、关系模型、度量、空间变换、规律推理、数据与不确定。

每节课只讲一个原理。B 卷题放在三层挑战里，作为原理的应用出口，不单独刷题。

范围是校内提优和少量轻奥，不接竞赛。竞赛专属内容放挑战卡或项目周，不占正课。

## 教材版本

项目默认按人教版编排，但不能把它当成成都学校的实际进度。成都部分学校使用北师大版；已核对到的旧版差异包括：小数乘法与方程（北师大旧版四下，本项目五上）、因数倍数与分数意义（旧版五上，本项目五下）、分数乘除（旧版五下，本项目六上）。2026 年新版和学校实际单元仍需确认。来源和边界见 [18 号研究依据](00-方案/18-成都教材与提高题研究依据.html)。

开学前先记四项：出版社、版次、学校当前单元、已学内容。未确认前按知识点选课，不按“三上/五上”硬套；需要时用下面的模块准入检查。填写入口和已知版本差异见 [19 号教材版本映射](00-方案/19-教材版本映射.html)。

## 一节课 75 分钟

| 时间 | 环节 | 做什么 |
|---|---|---|
| 0–5 | 开场 | 先猜，再验证 |
| 5–20 | 动手 | 小棒、方格纸、剪刀、纸杯 |
| 20–30 | 讲解 | 看视频，或家长按讲授稿讲 |
| 30–45 | 对话 | 四个问题，画一张图 |
| 45–65 | 挑战 | A 基础、B 变式、C 轻奥 |
| 65–75 | 复述 | 孩子讲，家长听，写原理卡 |

时间紧就做 30 分钟版：看视频或听讲解，做一个实验，做 A 层加一道 B 层，最后说一句话。

## 怎么开始

1. 做一次 `00-方案/05-入学诊断.html`。8 个问题，记录原话，不打分。
2. 准备材料：小棒、皮筋、方格纸、剪刀、扑克牌、纸杯。
3. 选起点：三年级从三上 L01 开始；五、六年级先做下面的模块准入检查，再决定从哪课开始。
4. 每周一课。一节课只完成一个实验也可以。

## 开始前的准入检查

先确认要学的模块，不做一张覆盖所有年级的统测。每项记三种状态：没学过、学过但卡住、能独立做。没学过不是失败，补对应前置即可。

| 准备学的模块 | 只查这些前置 | 没学过时 |
|---|---|---|
| 五上 01 小数乘法 | 整数乘法、十进位值、小数意义（0.1 是 1/10） | 三上 01–02 的位值和竖式；三下 06 的小数意义 |
| 五上 02 小数除法 | 整数除法竖式、商不变、小数意义 | 三下 01 的除法竖式；五上 02 的商不变段 |
| 五下 09–11 分数 | 分数单位、通分、同分母加减 | 三上 10 的分数初步；五下 09–10 |
| 六上 03–04 比 | 除法、分数、比的意义 | 五下分数与除法 |
| 五下 06–08 体积 | 面积、体积单位、长方体展开图 | 三下 03–05；五下 06 |

每一项记四件事：算对没有、会不会画图、能不能解释、需要多少提示。能独立做就直接进课；学过但卡住就补对应课；没学过先补前置，不要用分数、比或体积去卡小数乘法的入口。

## 本地阅读与构建

直接打开 `index.html` 就能读。重新生成 HTML：

```bash
npm install
npm run build
```

需要 Node 18 以上。构建脚本在 `工具/build_html.js`。

重渲染已有视频：

```bash
python3 工具/render_episode.py 工具/episodes/L01.json --out 课程/三上/L01-满十进一/视频.mp4
```

需要 Python 3、Pillow、ffmpeg，以及 macOS 的 `say`（音色 Tingting）。五、六年级暂时不生成视频。
