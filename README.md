# 小学数学 · 三至六年级原理与提高课

一套面向小学三至六年级的数学课程，共 125 课，分为基础、提高与轻奥。其中 49 课配有数学原理动画。适合孩子学习，也方便家长陪学、教师选用。

课程从具体问题出发，用小棒、方格、线段图和图形变化解释数学：竖式里为什么要进位，分数怎样表示一部分，图形剪开再拼好为什么面积不变。理解这些关系后，再用算式解决问题，并通过提高题练习不同的用法。

下载项目后，用浏览器打开根目录的 [index.html](index.html)，即可进入课程。也可以打开 [课程目录](课程/index.html) 选课。

## 课程内容

课程涵盖数与运算、数量关系、图形与几何、统计与可能性，以及测量、调查等实践活动。

三至六年级共四个学年、八个学期。这里的一课是一个学习主题，可能包含几个相关知识点和分次学习的小节，不等于学校的一课时。

课程按三、四年级和五、六年级两个阶段组织，每个阶段分为三类：

- **基础**：理解算理、掌握基本方法，涵盖整数、小数、分数、图形、统计等内容。
- **提高选学**：综合使用学过的知识，处理条件变化、图形切拼和生活中的多步问题。
- **轻奥选学**：通过画图、列表、枚举、假设和找规律练习推理，包含搭配、周期、植树、鸡兔同笼、数字谜、找次品、鸽巢问题等 13 课入门内容。

“轻奥”是本项目对兴趣拓展内容的分类，可以与教材题型有交叉。先用小学知识解释方法，再尝试变化题；不按竞赛训练组织课程。

每课开头列出需要先掌握的知识。正文包含原理讲解、例题、练习及答案，部分课程另附可打印的动手单和挑战单。有动画的课程会标出“▶ 视频”；动画用来展示分组、拆分、移动、剪拼等变化过程。

课程面向成都地区的日常学习与提高需求，按知识关系组织，适合作为校内学习的补充。可结合孩子的课本进度选课，提高与衔接内容按需学习。

## 知识点与练习

每课页面顶部列出本课知识点。如果相关基础还不熟，可以通过“可以先学”中的链接回头复习。知识点和前置课程存放在 `课程/学习安排.json`，调整课程时可以一起维护。

每课末尾有一组练习：每次 5 道四选一题，包含计算题和概念题，同一组内题干不重复。计算题会更换数字；概念题从本课题库抽取，换组后可能再次出现。题库维护在 `assets/practice-g*.js` 中。

做错题的知识点会记在浏览器里，同一知识点连对 2 次，就从待练列表中移除。换一组时，会优先练这些知识点，再搭配其他题复习。换设备、浏览器或访问域名时，记录不会同步；清空浏览器数据也会删掉记录。这组题用于巩固，不替代课中的讲解、动手单和挑战单。

## 怎样学习

1. 选一课，先看看课首的“先会”，确认相关基础已经掌握。
2. 阅读讲解；遇到动画或动手任务，跟着画一画、摆一摆、算一算。
3. 独立完成练习，再核对答案和解法。
4. 试着说清楚每一步为什么这样做，再尝试提高题。

测量、画图等活动需要纸笔、尺子、方格纸等简单材料，具体要求见课程正文或动手单。内容较多的课可以分几次学习。

## 本地使用与修改

阅读课程直接打开 HTML 文件即可，无需安装依赖或启动服务。练习记录建议在同一网站地址下使用；直接打开本地文件时，各页面的记录可能无法互通。

课程的 Markdown 文件是内容源文件，HTML 文件是阅读页面。修改内容后，在 Node.js 环境中生成页面：

```bash
npm ci
npm run build
```

主要目录：

| `assets/home.css` | 首页布局与手机样式 |

页面结构在模板中修改，首页外观在 `assets/home.css` 中修改，全站公共样式在 `assets/doc.css` 中修改。HTML 是生成结果，直接修改其中的内容会在下次构建时被覆盖。

修改目录或页面模板后，可运行 `npm run test:site` 检查课程清单、目录顺序和视频标识。

## 网站部署

运行 `npm run build:public`，将生成的 `dist/` 目录部署到静态托管平台。发布目录包含课程阅读页、练习、配图、成片和网页字幕；分镜、配音源文件和制作工具保留在仓库中。

Cloudflare Pages 配置：框架选择 `None`，构建命令为 `npm run build:public`，输出目录为 `dist`，生产分支为 `main`。连接 GitHub 仓库后，推送到该分支即可自动更新网站。

## 修改视频

有成片的课程保留了分镜配置、分幕配音和字幕，配音使用“开朗学长”音色（`zh_male_kailangxuezhang_uranus_bigtts`），语速为自然语速的 1.2 倍（豆包 `speech_rate=20`）。文字版分镜在各课的 `视频稿与分镜.md` 中。

视频工具使用 Python 3、Pillow 和 FFmpeg，目前使用 macOS 自带中文字体。每幕会按图形的实际大小调整取景，结论放在底栏。旁白字幕由 `视频.vtt` 提供，可在播放器里开关。批量命令会加入片头、片尾，并使用 1.2 倍配音。已有配音可直接复用，例如：

```bash
python3 工具/batch_videos.py render 课程/三上/L03-乘法的形状/视频源文件/分镜.json
```

渲染结果、日志和检查图片放在 `.cache/videos/`，不会覆盖课程中的成片。确认画面和声音后发布：

```bash
python3 工具/publish_videos.py 课程/三上/L03-乘法的形状/视频源文件/分镜.json --storyboard
```

发布命令会写入成片、SRT/VTT、时间线，并从片头截取 `poster.jpg`；`--storyboard` 会把 `视频稿与分镜.md` 表格中的时间改成当前成片时间。时间线中的源文件路径相对于其所在目录。

换声音、改语速或修改旁白时，用 `工具/prepare_narration.py --speech-rate 20` 指定新的配音目录，再更新分镜配置中的 `audio_version`。生成配音复用相邻 `nba_biz` 项目的 `scripts/tts.py` 及其本地配置；阅读课程和使用已有配音渲染均不需要配音服务。
