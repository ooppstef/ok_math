# 小学数学 · 三到六年级 B 卷原理课

一套给家长用的课程包。覆盖三年级到六年级的 B 卷知识点，不按题型刷题。每节课只讲一个“为什么”，配一个动手实验和三层挑战。

三、四年级已有样课和两段视频。五、六年级先写课稿，等你人工 review 通过，再做视频。

## 这套课怎么想

三到六年级的 B 卷题，难点常在“从哪下手”。同一个知识点，换个问法，孩子就认不出来。

这套课把教材知识点归到 8 条原理线索：位值、等价与守恒、运算结构、关系模型、度量、空间变换、规律推理、数据与不确定。

每节课只讲一个原理。B 卷题放在三层挑战里，作为原理的应用出口，不单独刷题。

## 一节课 70 分钟

1. 开场赌局：先猜，再验证。
2. 动手实验：小棒、方格纸、剪刀、纸杯。
3. 看视频或听讲解：3–5 分钟，只讲一个点。
4. 四个问题：从“是什么”问到“为什么”。
5. 三层挑战：A 基础、B 变式、C 轻奥。
6. 费曼复述：孩子用自己的话讲一遍，写原理卡。

## 怎么开始

1. 做一次 `00-方案/05-入学诊断.html`。8 个问题，记录原话，不打分。
2. 准备材料：小棒、皮筋、方格纸、剪刀、扑克牌、纸杯。
3. 三年级从 `课程/三上/L01-满十进一/讲授稿.html` 开始；五、六年级从 `课程/五上/L01-小数乘法/讲授稿.html` 开始。
4. 每周一课。一节课只完成一个实验也可以。

## 重新生成

阅读版：

```bash
npm install
npm run build
```

需要 Node 18 以上。构建脚本在 `工具/build_html.js`。

视频：

```bash
python3 工具/render_episode.py 工具/episodes/L01.json --out 课程/三上/L01-满十进一/视频.mp4
```

需要 Python 3、Pillow、ffmpeg，以及 macOS 的 `say`（音色 Tingting）。五、六年级暂时不生成视频。
