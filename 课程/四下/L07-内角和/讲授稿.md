# 第 7 课：内角和

## 一句话

任意三角形的三个内角加起来都是 180°，因为三个角可以拼成一个平角。

## 为什么

先看一个直角三角形：一个角 90°，另外两个锐角加起来正好 90°，总和 180°。但只验证一种三角形不够，要说明所有三角形都成立。

用平行线看。三角形 ABC 中，过顶点 A 画一条与底边 BC 平行的直线 DE。

```
 D --------- A --------- E
              /\
             /  \
            B----C
```

AB 与 DE 形成的 ∠DAB，和 ∠B 是内错角，相等；AC 与 DE 形成的 ∠CAE，和 ∠C 也是内错角，相等。

于是 A 点处从左到右的三个角，分别是 ∠B、∠A、∠C。它们正好排在直线 DE 上，组成一个平角。平角是 180°，所以 ∠A+∠B+∠C=180°。

由此可以推出：

- 已知两个角，第三个角=180°−两个角的和；
- 直角三角形里，两个锐角的和是 90°；
- 等边三角形每个角都是 180°÷3=60°；
- 四边形可以连一条对角线分成两个三角形，内角和是 180°×2=360°。

## 例子

### 例 1：已知两个角

三角形两个角是 50° 和 60°，第三个角是：

180°−50°−60°=70°。

### 例 2：直角三角形

直角三角形有一个角是 90°，一个锐角是 35°，另一个锐角是：

180°−90°−35°=55°。

也可以直接算 90°−35°=55°。

### 例 3：等腰三角形

等腰三角形的顶角是 40°，两个底角相等：

(180°−40°)÷2=140°÷2=70°。

每个底角是 70°。

## 易错

- 把 180° 当成每个角。三角形可以三个角都不同，和才是 180°。
- 以为三角形画得越大，内角和越大。角的大小与边长无关，内角和始终是 180°。
- 已知两个角，用 360° 去减。三角形用 180°，四边形才用 360°。
- 等腰三角形求底角，忘了先减顶角再除以 2。
- 认为直角三角形可以有两个 90°。两个 90° 已经是 180°，第三个角变成 0°，不可能。
- 把外角当内角。外角和相邻的内角相加是 180°，不是三角形的内角和。

## 练习

1. 三角形两个角是 45° 和 65°，第三个角是多少？
2. 直角三角形的一个锐角是 28°，另一个锐角是多少？
3. 等腰三角形的顶角是 80°，每个底角是多少？
4. 三角形两个角是 90° 和 50°，第三个角是多少？
5. 判断：三角形三个角可能是 40°、60°、90° 吗？
6. 四边形内角和是多少度？

## 答案

1. 180°−45°−65°=70°。
2. 90°−28°=62°。
3. (180°−80°)÷2=100°÷2=50°。
4. 180°−90°−50°=40°。
5. 不可以。40°+60°+90°=190°，超过 180°。
6. 360°。连接一条对角线，分成两个三角形，180°×2=360°。
