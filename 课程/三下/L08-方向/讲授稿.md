# 第 8 课：方向

说方向，先说清楚站在哪里看，再找准北。地图通常按上北下南来画，有指向标时，要按指向标认方向。

## 先说清楚站在哪里看

东南西北四个方向，先定北，其余三个就定了：

```
        北
        ↑
  西 ←  ·  → 东
        ↓
        南
```

在我国大部分地区，中午的太阳在正南，影子指向正北。这是最早确定南北的办法。指南针的磁针大致指向南北，让阴天也能定方向。

方向描述的是“谁在谁的哪一边”。A 在 B 的东边，反过来 B 就在 A 的西边。参照物换了，说法也换了。

地图是把地面按同一套约定画在纸上：上面是北，下面是南，右边是东，左边是西。这样任何人拿到同一张图，都能读出同一条路线。上北下南不是地理规律，只是画图人的约定。地图上有指向标时，以指向标为准；没有指向标时，通常默认上北下南。

八个方向：

- 正方向：东、南、西、北；
- 斜方向：东北、东南、西南、西北。

东北在东和北的正中间，不是“东边再偏一点”的模糊说法。

## 例子

### 例 1：面向北转圈

面向北时：前面是北，后面是南，右面是东，左面是西。

向右转 90°，面向东；再向右转 90°，面向南；再向右转 90°，面向西；再转一次，回到北。

### 例 2：相对位置

图书馆在学校的东南方向，那么学校在图书馆的西北方向。

“东南”和“西北”正好相反，就像“东”和“西”相反。

### 例 3：路线返回

从学校出发，向东走 200 米到书店，再向北走 150 米到公园。

```
学校 — 东 200 米 → 书店 — 北 150 米 → 公园
```

返回时倒着走：从公园向南走 150 米到书店，再向西走 200 米到学校。

## 易错

- 把“左”当成“西”。只有面向北时，左才是西；面向南时，左是东。
- 说相对位置时参照物弄反：A 在 B 的东边，B 就在 A 的西边，不是东边。
- 地图上有指向标，还硬按“上北下南”读。
- 把东北理解成“东边偏北一点点”，实际是东和北的正中间。
- 返回路线只把方向反过来，忘了路程顺序也要倒过来。

## 练习

1. 面向北，向左转 90°，面向哪边？
2. 面向南，向后转，面向哪边？
3. 图书馆在学校的东南方向，学校在图书馆的什么方向？
4. 地图上面是北，右边和左边分别是什么方向？
5. 从家出发向北走到路口，再向东走到超市。回家怎么走？
6. 判断：地图一定上北下南。

## 答案

1. 西。
2. 北。
3. 西北。
4. 右边是东，左边是西。
5. 先向西走到路口，再向南走回家。
6. 错。有指向标时按指向标；没有指向标时通常默认上北下南。
