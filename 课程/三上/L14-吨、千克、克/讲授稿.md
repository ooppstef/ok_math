# 第 14 课：吨、千克、克

## 一句话

质量单位是不同大小的“包”：1 千克=1000 克，1 吨=1000 千克；选哪个单位，要看东西有多重。

## 为什么需要三个单位

称一支铅笔，用“克”合适；称一袋大米，用“千克”合适；称一辆卡车，用“吨”合适。

如果用克表示卡车，数字会大得难读；如果用吨表示铅笔，数字会小得看不清。单位不是随便定的，它是为了让人一眼知道“大概有多重”。

常见的量感：

- 1 克：一枚回形针、一粒花生米，大约 1 克。
- 1 千克：4 个苹果、1 升水，大约 1 千克。
- 1 吨：一辆小汽车、10 袋 100 千克的大米，大约 1 吨。

## 单位之间的关系

```
1 千克 = 1000 克
1 吨 = 1000 千克
```

大单位换小单位，乘 1000；小单位换大单位，除以 1000。

```
3 千克 = 3000 克
2 吨 = 2000 千克
4500 克 = 4 千克 500 克
8000 千克 = 8 吨
```

## 例子

### 例 1：千克换克

一箱苹果重 5 千克，是多少克？

```
5×1000=5000（克）
```

### 例 2：吨换千克

一辆小货车载重 3 吨，是多少千克？

```
3×1000=3000（千克）
```

### 例 3：克换千克

一袋米重 2500 克，是多少千克多少克？

```
2500 克 = 2 千克 500 克
```

### 例 4：比较大小

比较 3 吨和 2800 千克。

先统一单位：

```
3 吨 = 3000 千克
3000 > 2800
```

所以 3 吨比 2800 千克重。

### 例 5：选择单位

在括号里填上合适的单位：

- 一个鸡蛋约 50（克）
- 一袋大米约 25（千克）
- 一辆卡车约 8（吨）

## 易错

- 把 1 吨当成 1000 克。吨和克中间还隔着千克。
- 千克换克时少写一个 0，或者多写一个 0。
- 比较大小前没有统一单位。
- 把“斤”和“千克”混着用。斤不是课本里的质量单位，计算时先统一成千克或克。
- 填单位只看数字大小，不看东西的实际重量。

## 练习

1. 4 千克等于多少克？
2. 6 吨等于多少千克？
3. 3200 克等于多少千克多少克？
4. 1 吨 200 千克等于多少千克？
5. 比较：5 吨和 4800 千克，哪个重？
6. 填单位：一个西瓜约 4（ ），一辆卡车约 10（ ）。

## 答案

1. 4000 克。
2. 6000 千克。
3. 3 千克 200 克。
4. 1200 千克。
5. 5 吨=5000 千克，5000>4800，所以 5 吨重。
6. 千克；吨。
