第 6 课：0 的隐身术

本学期课程

0 既表示“一个也没有”，又负责占住数位；去掉它，数字会挤到别的数位上，数就变了。

中间的 0 为什么不能省

写数时，每个数位只用一个数字，最多写到 9。某个数位上一个单位也没有，就要写 0 占位。漏写这个 0，前面的数字就会占到右边的数位上，表示的大小也变了。

看 208：

百位 十位 个位
2 0 8

它表示 2 个百、0 个十、8 个一，读作二百零八。

十位上的 0 不能省。写成 28，2 就从百位滑到了十位，8 还在个位，数变成了二十八。

同样是 0，放在不同的位置，作用不同：

  • 208 里的 0 占十位，表示“没有十”；
  • 280 里的 0 占个位，表示“没有一”，但 8 在十位，280 是 28 个十；
  • 802 里的 0 占十位，8 在百位，2 在个位。

0 还会影响计算。30 是 3 个十，30×4 是 12 个十，也就是 120。去掉 0 算 3×4=12，就把“十”这个单位丢了，结果只有原来的十分之一。

例子

例 1：208、280、802

  • 208=200+0+8；
  • 280=200+80+0；
  • 802=800+0+2。

三个数都用了 2、0、8，但 0 的位置不同，数的大小也不同。

从小到大排列：208<280<802。

例 2：1000−368

个位 0 减 8 不够，向十位借；十位是 0，没有可借的，再向百位借；百位也是 0，再向千位借。

借的过程可以写成：

  • 1 个千换成 10 个百；
  • 从 10 个百里拿 1 个百，换成 10 个十；
  • 从 10 个十里拿 1 个十，换成 10 个一。

这时千位是 0，百位剩 9，十位剩 9，个位是 10。

个位：10−8=2； 十位：9−6=3； 百位：9−3=6。

所以 1000−368=632。检验：632+368=1000。

例 3：30×4

30 是 3 个十。3 个十乘 4，得到 12 个十。

12 个十就是 120，所以 30×4=120。

如果先算 3×4=12，最后要记得把“十”补回来，写成 120。去掉末尾的 0，结果就缩小到原来的十分之一。

易错

  • 读写中间有 0 的数时漏写 0，比如把二百零八写成 28。
  • 把 280 末尾的 0 去掉，以为大小不变。280 变成 28，缩小到原来的十分之一。
  • 减法遇到连续的 0 不会借位，直接从高位拿数。
  • 计算 30×4 时先算 3×4=12，最后忘记补 0。
  • 认为 0 没有用，可以随便删。这里看的是整数写法，0 在中间或末尾承担占位作用；以后学小数时，要再看它所在的位置。

遮住 0 和删掉 0 一样吗

在“百、十、个”的表格里填 2、0、8。只把 0 遮住、保留空着的十位，和把十位这一格挤掉，都还是 208 吗？

看解释

保留三列时，2 仍在百位，8 仍在个位，表示 208。写在表格外时，空格容易丢失，所以要写 0。挤成 28 后，2 就在十位了，只表示 28。

练习

  1. 读出 506、560、605，并按从小到大排列。
  2. 用 0、4、7 组成最大的三位数和最小的三位数。
  3. 计算 400−136，并用加法检验。
  4. 计算 40×5，并说明它和 4×5 的区别。
  5. 判断：把 580 末尾的 0 去掉，数的大小不变。
  6. 3005 的百位和十位都是 0。这两个 0 各表示什么？

答案

  1. 506 读作五百零六；560 读作五百六十；605 读作六百零五。506<560<605。
  2. 最大是 740；最小是 407。最高位不能是 0，所以 047 不行。
  3. 400−136=264；264+136=400。
  4. 40×5=200；4×5=20。40 是 4 个十，乘 5 得 20 个十，也就是 200，是 4×5 的 10 倍。
  5. 错。580 是 58 个十，去掉 0 变成 58，缩小到原来的十分之一。
  6. 百位的 0 表示没有百，十位的 0 表示没有十；它们占住位置，3 才在千位，5 才在个位。3005=3000+5。
