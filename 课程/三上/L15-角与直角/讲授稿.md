# 第 15 课：角与直角

## 一句话

角由一个顶点和两条边组成；角的大小看两条边张开的程度，不看边画得多长。

## 角是什么

从一点出发，画两条射线，就得到一个角。

```
       边
        \
         \
          ● 顶点
         /
        /
       边
```

这个点叫顶点，两条射线叫角的边。

角的两条边可以延长，但角的大小不变。就像把一扇门推开一点，门框的两条边变长了，门开的角度还是那个角度。

## 角的大小看什么

看两条边张开得有多大，不看边有多长。

比较两个角时，把两个角的顶点重合，一条边重合，再看另一条边落在哪里：

- 另一条边落在里面，这个角小；
- 另一条边落在外面，这个角大。

不能因为一个角的边画得长，就说它大。

## 直角、锐角和钝角

- **直角**：两条边张开到正好“方方正正”，以后会用 90° 表示。
- **锐角**：比直角小。
- **钝角**：比直角大，但还没有张成一条直线。

判断直角，可以用三角尺上的直角去比：顶点对顶点，一条边对一条边，看另一条边是否重合。

## 例子

### 例 1：找直角

书本的角、窗框的角、桌面的角，通常都是直角。用三角尺的直角去比一比。

### 例 2：画直角

1. 先画一条边；
2. 把三角尺的直角顶点对准边的端点，一条直角边对齐；
3. 沿另一条直角边画线。

### 例 3：比较两个角

一个角的两条边画得很长，另一个角的两条边画得很短。把顶点和一条边重合后，如果长边的角另一条边落在里面，它反而更小。

### 例 4：钟面上的角

3 时整，时针指向 3，分针指向 12，两针之间是直角。

2 时整，两针张开得比直角小，是锐角。

4 时整，两针张开得比直角大，是钝角。

## 易错

- 认为边越长，角越大。
- 认为直角都必须“朝同一个方向”。直角可以朝上、朝下、斜着放。
- 把角的边画成线段就停了。角的两边是射线，可以延长。
- 用眼睛估直角，不用三角尺比。
- 把钝角和锐角说反。

## 练习

1. 一个角有一个（ ）和两条（ ）。
2. 判断：角的两条边越长，角越大。（ ）
3. 用三角尺比一比，下面哪些角是直角？
4. 画一个直角，再画一个比它小的角。
5. 3 时整，时针和分针成什么角？
6. 说出生活中三个有直角的地方。

## 答案

1. 顶点；边。
2. 错。角的大小看张开程度，不看边的长短。
3. 用三角尺的直角顶点对顶点、边对边比，能重合的是直角。
4. 按“先画一条边，再用三角尺的直角对齐画另一条边”的步骤画。
5. 直角。
6. 书本角、窗框角、桌面角等。
