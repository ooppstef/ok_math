# 第 13 课：混合运算与括号

## 一句话

运算顺序是为了让同一个算式只有一个答案：先乘除，后加减；有括号，先算括号里面。

## 为什么不能从左往右算

看一个买东西的式子：

```
3 支笔，每支 5 元；2 本本子，每本 4 元。一共多少钱？
```

写成算式是 `3×5+2×4`。

- `3×5` 是 3 支笔的钱，一共 15 元；
- `2×4` 是 2 本本子的钱，一共 8 元；
- 合起来是 15+8=23 元。

`3×5` 和 `2×4` 各自是一个整体，不能把 5 和 4 先加起来：它们代表不同的东西。乘号两边是“几个几”，要先算成一个整体，再去加。

所以约定：**先算乘除，再算加减**。

## 括号的作用

括号是“优先标记”：括号里面的部分，先算成一个整体。

```
(3+4)×5
```

先算 `3+4=7`，再算 `7×5=35`。它表示 7 个 5。

如果没有括号：

```
3+4×5
```

先算 `4×5=20`，再算 `3+20=23`。它表示 3 再加 4 个 5。

同一个算式里，括号的位置不同，结果就不同。括号不是装饰，它改变了“先算哪一步”。

## 同级运算从左往右

加法和减法在同一级，乘法和除法在同一级。

```
100-40+25
```

减法和加法同级，从左往右：先 `100-40=60`，再 `60+25=85`。

```
100÷4×5
```

除法和乘法同级，从左往右：先 `100÷4=25`，再 `25×5=125`。

同级运算不能随便先算后面那一步。比如 `100-40+25` 如果先算 `40+25=65`，就变成 `100-65=35`，错了。

## 例子

### 例 1：先乘后加

```
6×4+3×5
=24+15
=39
```

### 例 2：先乘后减

```
50-5×6
=50-30
=20
```

### 例 3：括号优先

```
(8+7)×4
=15×4
=60
```

### 例 4：括号改变结果

```
72÷(9-3)
=72÷6
=12
```

如果不加括号：

```
72÷9-3
=8-3
=5
```

### 例 5：同级从左往右

```
100-30+20
=70+20
=90
```

## 易错

- 从左往右一路算，忽略“先乘除后加减”。
- 括号里面还有乘除时，没有先算括号里的乘除。
- 同级运算跳步，先算了后面那一步。
- 把括号当成“可有可无”，忘了它会改变结果。
- 写递等式时漏写中间步骤，答案对但过程看不清。

## 练习

1. 计算：`6×4+3×5`
2. 计算：`50-5×6`
3. 计算：`(8+7)×4`
4. 计算：`72÷(9-3)`
5. 计算：`100-30+20`
6. 在 `3+4×5` 里加一对括号，使结果变成 35。

## 答案

1. 24+15=39。
2. 50-30=20。
3. 15×4=60。
4. 72÷6=12。
5. 70+20=90。
6. `(3+4)×5=35`。
