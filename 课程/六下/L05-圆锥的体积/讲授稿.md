# 第 5 课：圆锥的体积

## 一句话

等底等高时，圆锥的体积是圆柱的 1/3，V=1/3×底面积×高。

## 为什么

圆锥和圆柱的底面一样大、高也一样时，圆锥只占圆柱的一部分。这个比是 1:3，不是 1:2。

为什么是 1/3？把圆锥看成一层层圆片：最底下的一层和底面一样大，越往上圆片越小，到顶端缩成一个点。越往上缩得越快，所以这些圆片的平均面积不是底面积的 1/2，而是 1/3。圆柱每一层都一样大，所以同样高度下，圆锥的体积是圆柱的 1/3。

```
   圆锥              圆柱
     △               ┌────┐
    △△               │    │
   △△△               │    │
  △△△△               └────┘
 逐渐缩小            每层一样
```

关系式：

```
V圆锥=1/3×S底×h
V圆柱=S底×h=3×V圆锥
```

“等底等高”四个字不能丢。底面或高不一样，1/3 的关系就不成立。

下面计算中，π 取 3.14。

## 例子

### 例 1：给底面积

S=30 cm²，h=9 cm。

```
V=1/3×30×9=10×9=90（cm³）
```

### 例 2：给半径

r=3 m，h=4 m。

```
S底=3.14×3²=28.26（m²）
V=1/3×28.26×4=28.26×4÷3=113.04÷3=37.68（m³）
```

### 例 3：沙堆

沙堆底面直径 4 m，高 1.5 m。

```
r=2 m
S底=3.14×2²=12.56（m²）
V=1/3×12.56×1.5=12.56×0.5=6.28（m³）
```

## 易错

- 忘记乘 1/3，把圆锥体积算成圆柱体积。
- 把 1/3 重复乘。V=1/3Sh 中三个数相乘，1/3 只出现一次。
- 底面或高不相同时，仍用 1/3 的关系。必须等底等高。
- 把直径当半径。d=4 m，r=2 m。
- 认为“圆锥体积是圆柱的 1/3”对任意圆柱都成立。只有等底等高的圆柱才是 3 倍。
- 体积单位写成平方单位。

## 练习

1. 圆锥底面积 24 dm²，高 6 dm，体积是多少？
2. 圆锥底面半径 2 cm，高 9 cm，体积是多少？
3. 圆锥底面直径 6 m，高 5 m，体积是多少？
4. 一个圆锥的体积是 60 cm³，底面积是 20 cm²，高是多少厘米？
5. 一个圆柱与一个圆锥等底等高，圆柱体积是 90 cm³，圆锥体积是多少？
6. 判断：任何一个圆锥的体积都是某个圆柱的 1/3。

## 答案

1. 1/3×24×6=48（dm³）。
2. 3.14×2²=12.56（cm²）；1/3×12.56×9=37.68（cm³）。
3. r=3 m；3.14×3²=28.26（m²）；1/3×28.26×5=47.1（m³）。
4. 60×3÷20=9（cm）。
5. 90÷3=30（cm³）。
6. 错。必须是等底等高的圆柱，圆锥体积才是它的 1/3。
