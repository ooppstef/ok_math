2. 3 的倍数

123 = 100 + 20 + 3。

  • 100 = 99 + 1；99 是 3 的倍数。
  • 20 = 18 + 2；18 是 3 的倍数。
  • 3 = 3。

所以 123 = 99 + 18 +（1 + 2 + 3）。

1 + 2 + 3 = __________。

123 是 3 的倍数吗？__________

7. 还没想通的问题

核对与说明

  • 拆一拆：20 和 4 都是 2 的倍数，24 也是；30 和 5 都是 5 的倍数，35 也是。六个空都填“是”。
  • 3 的倍数：1+2+3=6，6 是 3 的倍数，所以 123 是 3 的倍数。
  • 找规律：按下面的表核对。
数 个位 数字和 是 2 的倍数？ 是 5 的倍数？ 是 3 的倍数？
34 4 7 是 否 否
45 5 9 否 是 是
60 0 6 是 是 是
123 3 6 否 否 是
246 6 12 是 否 是
  • 填一填：第一题填 0；第二题可以填 1、4、7；第三题可以填 0、3、6、9。
  • 9 的倍数：234 的数字和是 9，567 的数字和是 18，所以两个数都是 9 的倍数。
  • 说一说：判断 2、5 的倍数，看个位；判断 3、9 的倍数，看数字和。10、100、1000……除以 2 或 5，余数是 0；除以 3 或 9，余数是 1。
