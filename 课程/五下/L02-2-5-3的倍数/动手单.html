2. 3 的倍数

123 = 100 + 20 + 3。

  • 100 = 99 + 1；99 是 3 的倍数。
  • 20 = 18 + 2；18 是 3 的倍数。
  • 3 = 3。

所以 123 = 99 + 18 +（1 + 2 + 3）。

1 + 2 + 3 = __________。
