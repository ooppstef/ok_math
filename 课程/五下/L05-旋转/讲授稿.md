# 第 5 课：旋转

**大问题**：转完之后，什么变了，什么没变？

**本课要点**：旋转是绕一个固定点转一定角度、按一定方向转动。旋转中心不动；图形的形状和大小不变，位置和方向变了；对应点到旋转中心的距离相等。

**时长**：75 分钟

**材料**：方格纸、三角形纸片、图钉/牙签、直尺、彩笔

## 0–5 分钟：开场

家长：把这张三角形绕点 O 转 90°，它会到哪里？

孩子：不知道，可能转过去了。

家长：先猜一猜：形状会变吗？大小会变吗？哪个点不动？

## 5–20 分钟：实验

### 定中心

在方格纸上画一个三角形，标出一个顶点 O，作为旋转中心。用图钉固定在 O 点。

家长：转的时候，O 点动不动？

孩子：不动。

家长：这叫旋转中心。

### 转 90°

家长：把三角形绕 O 顺时针转 90°。先看一个顶点 A 转到了哪里。

孩子转纸片，描下新位置 A'。

家长：O 到 A 的距离，和 O 到 A' 的距离一样吗？

孩子量：一样。

家长：对。旋转不改变点到中心的距离，也不改变图形的形状和大小。

### 再转 180°

家长：如果转 180°，会怎样？

孩子：像翻了个身，但方向也变了。

家长：180° 旋转和翻折一样吗？

孩子：不一样；旋转是转过去，翻折是沿一条线翻面。

## 20–35 分钟：讲解

家长：描述旋转，要说清三件事：

1. 绕哪个点转？
2. 顺时针还是逆时针？
3. 转多少度？

家长：只说“转一下”不够，中心、方向、角度都要说。

家长：旋转后，对应点到中心的距离相等；对应线段的长度相等；对应角相等。形状和大小不变，位置和方向变了。

### 一句话

家长：旋转绕定点转，中心不动，形状大小不变，位置方向改变。

## 35–50 分钟：四个问题

### 1. 你看到了什么

家长：转 90° 前后，哪些线段长度没变？

孩子：每条边都没变，O 到各顶点的距离也没变。

### 2. 为什么

家长：为什么中心 O 不动？

孩子：因为旋转就是绕 O 转，O 是固定的。

### 3. 你怎么证明

家长：怎么检查转对了 90°？

孩子：看对应点和 O 的连线，转过的角是 90°；对应点到 O 的距离相等。

### 4. 改一个条件

家长：如果绕另一个点转 90°，结果一样吗？

孩子：不一样，中心变了，位置就变了。

家长：如果逆时针转 90° 呢？

孩子：方向相反，位置也不同。

## 50–65 分钟：挑战

### A 层

1. 一个点 A 在 O 的右边 3 格。绕 O 顺时针转 90°，A 大约在哪？
2. 转 180° 后，A 在哪？
3. 旋转后图形的形状和大小变了吗？

答案：

1. 在 O 的下边 3 格（方向按钟面约定）。
2. 在 O 的左边 3 格。
3. 没变，位置和方向变了。

### B 层

1. 描述一次旋转，必须说清哪三件事？
2. 一个三角形绕 O 顺时针转 90°，再转 90°，一共转了多少度？和一次转 180° 一样吗？
3. 旋转和翻折有什么不同？

答案：

1. 中心、方向、角度。
2. 一共 180°；和一次转 180° 的最终位置一样（都绕同一个中心）。
3. 旋转绕点转，翻折沿直线翻面；旋转不翻面。

### C 层

一个点 A 在 O 的右边 4 格、上边 2 格。绕 O 顺时针转 90°，它到 O 的距离变了吗？转 180° 呢？

答案：距离都不变；到 O 的直线距离始终一样，小学阶段只需知道“距离不变”，不必算出具体长度。方向按旋转角度改变。

## 65–75 分钟：复述与原理卡

让孩子讲：为什么旋转中心不动，图形大小不变？

家长只问：中心在哪？方向是什么？转了多少度？

原理卡：

```
【课题】旋转
【本课要点】绕定点、按方向、转角度；中心不动，形状大小不变，位置方向变。
【一张图】三角形绕 O 顺时针转 90°，对应点到 O 的距离相等。
【一个反例】旋转不是翻折，不会把图形翻面。
【还没想通的问题】
```

## 常见错误

| 错误 | 怎么接 |
|---|---|
| 只说“转一下”，不说中心、方向、角度 | 三件事少一件都不完整 |
| 认为旋转会改变大小 | 量对应点到中心的距离、对应边长度 |
| 把旋转和翻折混在一起 | 旋转绕点，翻折沿直线；旋转不翻面 |
| 中心找错 | 先标固定点，再看它是否不动 |
| 顺时针、逆时针说反 | 用钟面或手势确认方向 |

## 30 分钟版

| 时间 | 做什么 |
|---|---|
| 0–5 | 猜绕 O 转 90° 会到哪里 |
| 5–15 | 用纸片转 90°，量对应点到 O 的距离 |
| 15–25 | A 层 + 一道 B 层 |
| 25–30 | 说“中心、方向、角度” |
