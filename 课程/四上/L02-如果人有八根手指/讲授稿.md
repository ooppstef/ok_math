# 第 2 课：进制：如果人有 8 根手指？

## 一句话

十进制只是选了 10 作打包单位；换成几进制，就满几进一。

## 为什么

我们平时写 235，意思是：

```
2 个百 + 3 个十 + 5 个一
= 2×100 + 3×10 + 5×1
```

每一位的“份量”是 10 的幂：1、10、100、1000……这就是十进制。

如果人有 8 根手指，最自然的打包单位会是 8。数到 7 以后，再添 1 个，就捆成 1 个八，写作 10。这里的 10 不读“十”，读“一零”，表示“1 个八、0 个一”。

八进制只用 0 到 7 这八个数字，没有 8 和 9。同样，五进制只用 0 到 4，二进制只用 0 和 1。

把其他进制化成十进制，就按位算：

```
1011₂ = 1×8 + 0×4 + 1×2 + 1×1 = 11
```

把十进制化成其他进制，就反复除以进制数，把余数从下往上读。

## 例子

### 例 1：十进制 45 写成五进制

```
45 ÷ 5 = 9 …… 0
 9 ÷ 5 = 1 …… 4
 1 ÷ 5 = 0 …… 1
```

余数从下往上读，是 140。所以 45 = 140₅。

检验：1×25+4×5+0=25+20=45。

### 例 2：二进制 1011 与十进制 11

```
1011₂ = 1×8 + 0×4 + 1×2 + 1×1 = 11
```

反过来，把 11 写成二进制：

```
11 ÷ 2 = 5 …… 1
 5 ÷ 2 = 2 …… 1
 2 ÷ 2 = 1 …… 0
 1 ÷ 2 = 0 …… 1
```

余数从下往上读，是 1011。所以 11 = 1011₂。

### 例 3：八进制 37 是多少

```
37₈ = 3×8 + 7 = 24+7 = 31
```

八进制里的 37，表示 3 个八和 7 个一，不是三十七。

## 易错

- 在八进制里写出 8 或 9。八进制的数字只有 0 到 7。
- 在五进制里写出 5。满 5 就要进到上一位。
- 把 10₈ 当成十。它表示 8。
- 换算时把位权弄反。从右往左依次是 1、进制数、进制数的平方……
- 除法取余数时从上往下读，顺序读反了。
- 写进制数时丢掉右下角的下标，别人就不知道它是几进制。

## 练习

1. 五进制数 23 化成十进制是多少？
2. 十进制 17 化成二进制是多少？
3. 八进制数 100 化成十进制是多少？
4. 二进制数 1101 化成十进制是多少？
5. 十进制 50 化成五进制是多少？
6. 判断：在八进制里，7+1=10。

## 答案

1. 2×5+3=13。
2. 17=16+1=10001₂。
3. 1×64=64。
4. 8+4+0+1=13。
5. 50=2×25，所以是 200₅。
6. 对。八进制满 8 进一，7 再加 1 就是 10₈。
