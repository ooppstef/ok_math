# 第 2 课：进制：如果人有 8 根手指？

## 选学说明

这是一节选学课。先弄懂“满十进一”，再试试“满八进一”。如果整数计算还不熟，可以先跳过。

给家长：八进制转换不作为三至六年级统一必修内容，也不作为成都 B 卷的通用要求。

十进制只是选了 10 作打包单位；换成几进制，就满几进一。

## 如果改成满八进一

我们平时写 235，意思是：

```
2 个百 + 3 个十 + 5 个一
= 2×100 + 3×10 + 5×1
```

从右往左，每一位的单位依次是 1、10、100、1000……左边一位总是右边一位的十倍，这就是十进制。

想象一下，如果用 8 根手指数数，每数满 8 个就捆成一包，会怎样？数到 7 以后，再添 1 个，就捆成 1 个八，写作 10。这里的 10 不读“十”，读“一零”，表示“1 个八、0 个一”。

八进制只用 0 到 7 这八个数字，没有 8 和 9。同样，五进制只用 0 到 4，二进制只用 0 和 1。

把其他进制化成十进制，就按位算：

```
1011₂ = 1×8 + 0×4 + 1×2 + 1×1 = 11
```

换一种打包办法时，先找零散的，再找整包的。比如 45 个小球每 5 个一包：装出 9 包，散球是 0；9 包再每 5 包扎一大捆：有 1 大捆，散包是 4。于是从大到小写成“1 大捆、4 包、0 个”，也就是 140₅。反复除以 5 时，最先得到的是最小单位的余数，所以记录结果要从后往前读。

## 例子

### 例 1：十进制 45 写成五进制

```
45 ÷ 5 = 9 …… 0
 9 ÷ 5 = 1 …… 4
 1 ÷ 5 = 0 …… 1
```

余数从下往上读，是 140。所以 45 = 140₅。

检验：1×25+4×5+0=25+20=45。

### 例 2：二进制 1011 与十进制 11

```
1011₂ = 1×8 + 0×4 + 1×2 + 1×1 = 11
```

反过来，把 11 写成二进制：

```
11 ÷ 2 = 5 …… 1
 5 ÷ 2 = 2 …… 1
 2 ÷ 2 = 1 …… 0
 1 ÷ 2 = 0 …… 1
```

余数从下往上读，是 1011。所以 11 = 1011₂。

### 例 3：八进制 37 是多少

```
37₈ = 3×8 + 7 = 24+7 = 31
```

八进制里的 37，表示 3 个八和 7 个一，不是三十七。

## 易错

- 在八进制里写出 8 或 9。八进制的数字只有 0 到 7。
- 在五进制里写出 5。满 5 就要进到上一位。
- 把 10₈ 当成十。它表示 8。
- 换算时把位权弄反。从右往左依次是 1、进制数、进制数的平方……
- 除法取余数时从上往下读，顺序读反了。
- 写进制数时丢掉右下角的下标，别人就不知道它是几进制。

## 练习

1. 五进制数 23 化成十进制是多少？
2. 十进制 17 化成二进制是多少？
3. 八进制数 100 化成十进制是多少？
4. 二进制数 1101 化成十进制是多少？
5. 十进制 50 化成五进制是多少？
6. 判断：在八进制里，7+1=10。

## 答案

1. 2×5+3=13。
2. 17=16+1=10001₂。
3. 1×64=64。
4. 8+4+0+1=13。
5. 50=2×25，所以是 200₅。
6. 对。八进制满 8 进一，7 再加 1 就是 10₈。
