图形稳定性：三角形为什么晃不动？

先会：三角形四边形识别、线段长度

本课知识点：三角形稳定性四边形易变形结构

可以先学：一个图形可以有两个名字吗（三、四年级 · 基础）

换一组练习课程目录

这是一节图形操作拓展。先会辨认三角形和四边形，再用活动接点的小棒比较形状；不要求提前学习用三边求角度或三角形全等证明。

用长度不变的小棒做框架，连接处可以转动。三角形和四边形都能转吗？试着动顶点，同时盯住每根棒的长度。

加一根斜撑，为什么就稳了

三根小棒钉成一个三角形后，三根棒的长度固定，三个角也被固定住了，推一推，形状不会变。可以固定底边，再想另外两根棒的自由端怎样碰到一起：顶点到两个底端的距离都已经固定，不能随意滑动。这就是三角形的稳定性。本课把小棒看作不会弯曲、伸缩的棒，连接处只允许转动。

四边形不一样。四根小棒钉成一个四边形，边长都没变，但四个角可以活动，轻轻一推就歪了。固定四条边的长度，还没有固定对角线的长度；推斜时，对角线和角都可以改变。

给四边形加一条对角线，它就分成两个三角形。每个三角形的三条边都被小棒固定住，形状不能再变，整个四边形的形状也就固定了。所以“加斜撑”能让四边形稳定。

稳定性说的是“形状不容易改变”，不是“材料更结实”。一个三角形框架可能很轻，但形状稳定；一个四边形框架用很粗的木头，照样可能晃。

例子

例 1：三根小棒和四根小棒

用 3 厘米、4 厘米、5 厘米三根小棒，只能围出一种形状的三角形。用三角尺的直角比一比，可以看出它还是一个直角三角形；这里不要求只凭三个边长计算角度。

用 3 厘米、4 厘米、5 厘米、6 厘米四根小棒，可以围出很多种四边形：压扁一点、拉斜一点，边长都没变，形状却变了。

注意：不是随便三根小棒都能围成三角形。比如 3 厘米、4 厘米、8 厘米就不行，因为 3+4<8，两根短的接起来都够不到第三根。

例 2：给四边形加斜撑

四边形：        加一条对角线：

  A────B            A────B
  |    |            |\\   |
  |    |            |  \\ |
  D────C            D────C

左边推一推会变形。右边加了 AC 以后，变成三角形 ABC 和三角形 ACD，两个三角形的边都固定了，整个框架就稳了。

例 3：生活中的应用

用三角形的地方：自行车车架、篮球架、屋顶的桁架、桥梁的钢架。它们都要保持形状不变。

用四边形的地方：伸缩门、升降晾衣架、折叠椅。它们需要能变形，所以反而利用四边形的不稳定性。

易错

  • 以为三角形稳定是因为三条边一样长。任意三角形只要三边固定，形状就固定。
  • 以为四边形不稳定就是“不结实”。不稳定指形状会变，不代表容易断。
  • 认为所有多边形都不稳定。加对角线后，四边形也可以稳定。
  • 忘了三角形三边关系：任意两边之和要大于第三边。
  • 把“稳定”理解成“重量大”或“材料硬”。

练习

  1. 三角形有几条边、几个角？
  2. 四根小棒钉成一个四边形，推一推会发生什么？
  3. 怎样让一个四边形框架稳定？
  4. 自行车车架为什么做成三角形？
  5. 判断：三角形稳定是因为三条边都相等。
  6. 举两个利用四边形不稳定性的例子。

答案

  1. 3 条边，3 个角。
  2. 会变形，边长不变，角的大小改变。
  3. 加一条对角线，把它分成两个三角形。
  4. 三角形三边固定后形状不变，这样的结构有助于保持形状；真实车架还要考虑材料和连接是否牢固。
  5. 错。稳定性来自三边确定后形状唯一，与三边是否相等无关。
  6. 伸缩门、升降晾衣架（折叠椅也可以）。
