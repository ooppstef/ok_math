# 第 4 课：平行与垂直：方向的关系

在纸上画两条直线。眼前没有碰到，延长以后就一定不会碰到吗？判断平行，要看它们的方向。

## 两条直线会不会相交

在同一平面内，两条不同直线的位置关系只有两种：相交，或者不相交。

如果两条直线方向完全相同，它们之间的距离处处一样，不管延长多远都不会碰面，这时叫互相平行，记作 a∥b。

如果两条直线相交，并且相交成的四个角都是直角，这时叫互相垂直，记作 a⊥b。垂直是相交里最特殊的一种：方向正好相差 90°。

画一条已知直线的平行线，可以配合使用直尺和三角尺：把三角尺的一条边贴住已知直线，用直尺抵住另一条边；按住直尺，让三角尺沿直尺滑动，到新位置再沿原来贴线的那条边画线。滑动时三角尺没有转动，两条线的方向就相同。

画垂线，就让三角尺的直角顶点落在已知直线上，一条直角边与已知直线重合，沿另一条直角边画线。画完要标上直角符号。

## 例子

### 例 1：长方形里的平行与垂直

长方形有两条长、两条宽。

- 两条长方向相同，互相平行；
- 两条宽方向相同，互相平行；
- 一条长和一条宽相交成直角，互相垂直。

所以长方形有两组平行线，相邻的两条边互相垂直。

### 例 2：垂直于同一条直线的两条直线

在同一平面内，两条不同直线 a 和 b 都垂直于直线 c。

a 与 c 相差 90°，b 与 c 也相差 90°，那么 a 与 b 的方向相同。所以 a∥b。

这也是一种检验平行的方法：看两条线是不是都垂直于同一条线。

### 例 3：三条直线最多几个交点

三条直线，每两条最多相交一次。

```
第一条与第二条：1 个
第一条与第三条：1 个
第二条与第三条：1 个
```

一共最多 3 个交点。如果其中有两条平行，交点就会少一个。

## 易错

- 说“不相交的两条直线一定平行”，漏掉了“在同一平面内”。在空间里，不相交的直线还可能方向不同。
- 把“垂直”当成“只要相交”。相交成直角才叫垂直。
- 画垂线时没有标直角符号，别人无法判断是不是垂直。
- 以为平行线之间的距离会越来越近或越来越远。平行线之间的距离处处相等。
- 把长方形的对边说成垂直。对边是平行，邻边才是垂直。

## 练习

1. 长方形有几组平行线？
2. 正方形相邻的两条边是什么关系？
3. 同一平面内，a∥b，b⊥c，那么 a 与 c 是什么关系？
4. 三条直线两两相交，最多有几个交点？
5. 判断：不相交的两条直线一定平行。
6. 过直线外一点，画已知直线的垂线，能画几条？

## 答案

1. 两组，分别是两条长和两条宽。
2. 互相垂直。
3. a⊥c。a 与 b 方向相同，b 与 c 相差 90°，所以 a 与 c 也相差 90°。
4. 3 个。
5. 错。必须加上“在同一平面内”。
6. 1 条。
