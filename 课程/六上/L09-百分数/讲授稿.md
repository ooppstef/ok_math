# 第 9 课：百分数

百分数表示一个数是另一个数的百分之几。它用来比较两个数，后面不带米、千克这样的单位。

## 都换成一百份来比较

百分数把分母固定成 100。

```
50%=50/100=1/2
25%=25/100=1/4
120%=120/100=6/5
```

“甲数是乙数的 50%”意思是：把乙数看作 100 份，甲数相当于其中的 50 份，也就是乙数的一半。

分母固定为 100，比较起来很直接。及格率 62.5% 和 60%，一眼就能看出前者高；如果写成分数 5/8 和 3/5，也能通分、化小数或用别的方法比较；统一成百分数后更便于一起读。

百分数说明的是“一个量占另一个量的多少”，并没有直接说长度是多少、重量是多少或有多少人，所以不带单位。

```
50%：一个数占另一个数的一半
50 米：一条具体的长度
```

“50% 米”是错的。可以说“增加了 20 人”，也可以说“增长了 20%”，但不能把两者混成“增长了 20% 人”。

分数可以表示具体的量，也可以表示关系；百分数只表示关系。1/2 米是一条具体的长度，50% 只能依附于某个整体：100 米的 50% 是 50 米，200 米的 50% 是 100 米。

百分数、分数、小数可以互化：

```
0.35=35%=7/20
3/8=0.375=37.5%
120%=1.2
```

百分数化小数，去掉百分号，再除以 100；小数化百分数，乘 100，再加百分号。

百分率表示部分占整体的百分之几：

```
百分率=部分÷总数×100%
```

出勤率、合格率、发芽率都不能超过 100%；增长率可以超过 100%，因为增长的部分可能比原来的量还多。

## 例子

### 例 1：及格率

全班 40 人，及格 25 人。

```
25÷40=0.625=62.5%
```

及格率是 62.5%。

### 例 2：三种写法

0.35、35%、7/20 表示同一个数。

```
0.35=35/100=35%
35%=35/100=7/20
```

### 例 3：比较大小

比较 1/3 和 30%。

```
1/3=10/30
30%=3/10=9/30
10/30>9/30
```

所以 1/3 大于 30%。

## 易错

- 给百分数加单位，写成“50% 米”“30% 千克”。百分数只表示关系，不能带单位。
- 认为 100%=100。100%=1，表示整体。
- 百分数化小数时只去掉百分号，不除以 100。0.5%=0.005，不是 0.5。
- 把 3/8 化成百分数时算成 3÷8=0.375%，应该是 37.5%。
- 求百分率时，分母用错。及格率的分母是全班人数，不是及格人数。
- 认为所有百分率都不能超过 100%。出勤率、合格率不能超过，增长率可以。

## 练习

1. 把 0.45、3/8、120% 分别化成另外两种形式。
2. 全班 50 人，今天出席 48 人，出席率是多少？
3. 一批种子 200 粒，发芽 190 粒，发芽率是多少？
4. 判断下面两句话对不对：
   （1）一根绳子长 30% 米。
   （2）男生人数占全班的 60%。
5. 把 2/3、0.6、66.7% 从大到小排列。

## 答案

1. 0.45=45%=9/20；3/8=0.375=37.5%；120%=1.2=6/5。
2. 48÷50=0.96=96%。
3. 190÷200=0.95=95%。
4. （1）错，百分数不能带单位；（2）对，60% 表示男生占全班人数的百分比。
5. 66.7%=667/1000=2001/3000，2/3=2000/3000，0.6=1800/3000；所以 66.7%>2/3>0.6。
