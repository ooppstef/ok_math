# 第 7 课：圆的面积

把圆分成许多小扇形再交错拼起来，越分越接近长方形；长是圆周长的一半 πr，宽是半径 r，所以圆的面积是 πr²。

## 把圆分开，再拼一拼

直接数圆里的方格不好数，因为圆的边是弯的。可以把圆转化成已经会算的图形。

把圆平均分成 16 份、32 份或更多份小扇形，然后一上一下交错拼起来：

```
      ／＼／＼／＼
     ／  ／  ／  ＼
    ｜  ｜  ｜   ｜
     ＼  ＼  ＼  ／
      ＼／＼／＼／
```

拼出的图形接近一个长方形。分的份数越多，每个小扇形的弧越短、越接近直线，拼出的边也越平，图形就越接近长方形。这样分割再拼，面积没有增减。

这个近似长方形的长，是圆周长的一半。圆周长是 2πr，一半就是 πr。宽是每个小扇形的半径，也就是 r。

```
长方形面积 = 长 × 宽
圆的面积   = πr × r = πr²
```

实际剪拼时，不管分了多少份，拼出的边还有小弧，得到的只是近似长方形。分得越细，它就越接近长方形。这样想能帮助我们理解公式；严格证明要用到以后才学的“极限”，这节课不用先学。

如果题目给的是直径，要先求半径：

```
r=d÷2
S=πr²
```

## 例子

### 例 1：半径 4 厘米的圆

```
S=3.14×4²
 =3.14×16
 =50.24（平方厘米）
```

注意 4²=4×4=16，不是 4×2。

### 例 2：直径 10 米的圆

先求半径：r=10÷2=5（米）。

```
S=3.14×5²
 =3.14×25
 =78.5（平方米）
```

### 例 3：圆环的面积

一个圆环，外圆半径 6 厘米，内圆半径 4 厘米。圆环的面积是大圆面积减去小圆面积。

```
S=3.14×6²−3.14×4²
 =3.14×(36−16)
 =3.14×20
 =62.8（平方厘米）
```

## 易错

- 把 r² 算成 2r。r=3 时，r²=9，不是 6。
- 题目给直径，直接用直径算面积。要先用 d÷2 求出半径。
- 面积单位写成厘米、米。面积要用平方厘米、平方米。
- 算半圆面积忘记除以 2；算半圆周长时又忘记加直径。两者不是一回事。
- 圆环面积写成 π(R−r)²。应该是 π(R²−r²)，先分别平方再相减。
- 把 3.14 当成精确值，题目要求保留几位小数时不按要求取近似值。

## 练习

1. 一个圆的半径是 3 厘米，面积是多少？
2. 一个圆的直径是 8 分米，面积是多少？
3. 一个圆的周长是 31.4 米，面积是多少？
4. 一个圆环的外圆半径是 5 厘米，内圆半径是 3 厘米，圆环面积是多少？
5. 一个半圆的半径是 2 米，它的面积是多少？周长是多少？

## 答案

1. S=3.14×3²=3.14×9=28.26（平方厘米）。
2. r=8÷2=4 分米；S=3.14×4²=3.14×16=50.24（平方分米）。
3. r=31.4÷3.14÷2=5 米；S=3.14×5²=3.14×25=78.5（平方米）。
4. S=3.14×(5²−3²)=3.14×(25−9)=3.14×16=50.24（平方厘米）。
5. 面积：3.14×2²÷2=3.14×4÷2=6.28（平方米）；周长：3.14×2+2×2=6.28+4=10.28（米）。
