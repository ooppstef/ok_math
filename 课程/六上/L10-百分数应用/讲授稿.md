# 第 10 课：百分数应用

原价先涨 20%，再降 20%，还能回到原价吗？先看清两次分别按哪个价格算，就能知道为什么回不去。

## 涨价和降价，分别按哪个价格算

一件商品原价 100 元，先涨 20%，再降 20%。

先涨 20%：涨的是 100 元的 20%，即 20 元。

```
100×(1+20%)=100×1.2=120（元）
```

再降 20%：这时的基础已经是 120 元，降的是 120 元的 20%，即 24 元。

```
120×(1−20%)=120×0.8=96（元）
```

最后是 96 元，比原价少 4 元，相当于原价的 96%。

```
100×1.2×0.8=96
```

两次变化的百分率不能直接相加减。第一次把 100 元看作单位“1”，第二次把涨后的 120 元看作单位“1”，算的已经不是同一笔钱。

如果先涨 25%，再降 20%，结果会回到原价：

```
100×1.25×0.8=100
```

因为 1.25×0.8=1。涨和降的百分率不一样，乘出来的倍数却可以互相抵消。

百分数应用的基本关系是：

```
现在的量=原来的量×(1±百分率)
原来的量=现在的量÷(1±百分率)
```

打八折，就是按原价的 80% 出售：

```
现价=原价×80%
原价=现价÷80%
```

“甲比乙多百分之几”，要用多出来的部分除以乙：

```
（甲−乙）÷乙
```

“乙比甲少百分之几”，要用少掉的部分除以甲。单位“1”不同，结果通常也不同。

## 例子

### 例 1：先涨 20%，再降 20%

原价 100 元。

```
涨后：100×1.2=120（元）
降后：120×0.8=96（元）
```

最后是 96 元，不是 100 元。

### 例 2：打八折

一件衣服原价 250 元，打八折出售。

```
250×80%=250×0.8=200（元）
```

如果已知现价是 200 元，打八折，原价就是：

```
200÷80%=200÷0.8=250（元）
```

### 例 3：增长百分之几

某班去年 40 人，今年 50 人。

```
（50−40）÷40=10÷40=25%
```

今年比去年增长 25%。注意分母是去年的 40 人，不是今年的 50 人。

## 易错

- 认为涨 20% 再降 20% 回到原价。实际是原价的 96%，少了 4%。
- 第二次降 20% 时，仍用原价乘 20%。这次要按涨后的价格来算。
- 求原价时用加法。现价 200 元是八折，原价是 200÷0.8=250 元，不能算成 200×(1+20%)=240 元。
- 把“八折”当成便宜 8 元，或当成原价的 8%。八折是原价的 80%。
- 比较两个量时用错单位“1”。甲比乙多 25%，乙比甲少 20%，不是同一个百分数。
- 把两次百分率直接相加。先涨 10% 再涨 10%，不是一共涨 20%，而是涨了 21%。

## 另一次短课：浓度先找盐和盐水

先会百分率、分数除法与简单方程。这里按质量算盐水浓度：盐的质量÷盐水的总质量×100%。盐水总质量=盐+水，分母不能只写水。以下均假设盐完全溶解，搅拌均匀；蒸发时只减少水，盐没有损失。

原有 200 克、浓度 10% 的盐水，含盐 20 克、水 180 克。下面四种操作分别从这杯原盐水出发：

| 操作 | 操作后的盐 | 操作后的盐水 | 浓度怎样算，什么没变 |
|---|---:|---:|---|
| 加水 50 克 | 20 克 | 250 克 | 20÷250=8%；盐不变 |
| 加盐 25 克 | 45 克 | 225 克 | 45÷225=20%；水不变 |
| 蒸发水 50 克 | 20 克 | 150 克 | 20÷150≈13.3%；盐不变 |
| 加入 100 克、20% 的盐水 | 40 克 | 300 克 | 40÷300≈13.3%；先分别求盐再相加 |

混合时不能直接把 10% 和 20% 平均成 15%，因为两份盐水的质量不同。

**自己练一练**

1. 300 克 10% 的盐水加水后变成 6%，加了多少水？
2. 200 克 20% 与 300 克 10% 的盐水混合，浓度是多少？
3. 150 克 20% 的盐水要加多少克盐，才能变成 25%？

**答案与解释**

1. 盐有 30 克，新盐水 30÷6%=500 克，加水 200 克。
2. 盐 40+30=70 克，盐水 500 克，浓度 14%。
3. 设加盐 x 克，30+x=(150+x)×25%，得 0.75x=7.5，x=10；检验 40÷160=25%。要说明加的是盐还是水，分子和分母分别怎样变化。

## 练习

1. 80 增加 25% 后是多少？
2. 200 减少 15% 后是多少？
3. 一件商品原价 400 元，先涨价 10%，再降价 10%，现价是多少？
4. 一件商品打七五折后是 180 元，原价是多少元？
5. 甲数是 50，乙数是 40。甲比乙多百分之几？乙比甲少百分之几？
6. 某数增加 20% 后是 60，这个数原来是多少？

## 答案

1. 80×(1+25%)=80×1.25=100。
2. 200×(1−15%)=200×0.85=170。
3. 400×1.1=440，440×0.9=396（元）。
4. 180÷75%=180÷0.75=240（元）。
5. 甲比乙多：(50−40)÷40=25%；乙比甲少：(50−40)÷50=20%。
6. 60÷(1+20%)=60÷1.2=50。
