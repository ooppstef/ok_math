# 第 1 课 挑战单：小数乘法

**对应课**：五上 01 小数乘法

**用法**：A 层验证原理，B 层换包装，C 层只做一道。做完先讲理由，再对答案。

## A 层

1. 0.6×0.7
2. 1.5×0.4
3. 0.25×8

## B 层

1. 0.125×0.8
2. 2.4×1.25
3. 0.03×0.4
4. 小明写：0.3×0.4=1.2。他错在哪？
5. 每千克 8.6 元，买 2.4 千克，大约多少钱？得数保留一位小数。

## C 层

两个正小数相乘，积一定比每个因数都小吗？

先举两个例子，再下结论。

## 答案与说明

### A 层

1. 0.42。6×7=42，两位小数。
2. 0.6。15×4=60，两位小数，0.60=0.6。
3. 2。25×8=200，两位小数，2.00=2。

### B 层

1. 0.1。125×8=1000；0.125 有 3 位小数，0.8 有 1 位，一共 4 位，0.1000=0.1。
2. 3。24×125=3000；2.4 有 1 位，1.25 有 2 位，一共 3 位，3.000=3。
3. 0.012。3×4=12；0.03 有 2 位，0.4 有 1 位，一共 3 位。
4. 他只算了 3×4=12，没有数小数位数。0.3×0.4 是两位小数，应该是 0.12。还可以用估算检查：0.3×0.4 比 0.3 小，1.2 太大了。
5. 8.6×2.4=20.64，保留一位小数约 20.6 元。

### C 层

不一定。

- 0.3×0.4=0.12，比 0.3 和 0.4 都小。
- 1.5×2=3，比 1.5 和 2 都大。
- 0.5×2=1，比 0.5 大，比 2 小。

结论：两个正因数都小于 1 时，积小于每个因数；只要有一个因数大于 1，积就可能变大。一个因数等于 1 时，积等于另一个因数。这里只讨论正数；0×0.4=0，积等于 0，不是小于两个因数。

## 边界

- 积的末尾有 0，先点小数点，再化简。
- 点小数点时，按两个因数的小数位数和确定位数；点完再看末尾的 0，化简后的位数可能减少，如 0.25×8=2.00=2。
- 估算可以用来检查小数点有没有点错。
