# 第 1 课：小数乘法

**大问题**：小数点为什么能“搬家”？

**本课要点**：小数乘法先按整数乘，再按两个因数的小数位数和点小数点；本质是数位在缩放。

**时长**：70 分钟

**材料**：方格纸（10×10 一张，另备几张）、彩笔、直尺、计算器

## 0–5 分钟：开场

家长：先别算。0.3×0.4，你猜是 1.2 还是 0.12？

孩子：1.2？因为 3×4=12。

家长：把你的猜测写下来。写完我们不改，最后再看。

家长：再猜一个：0.3×0.4 的结果，比 0.3 大还是小？

孩子：小……吧。

家长：为什么？

孩子：因为 0.4 比 1 小。

家长：这个感觉很重要。乘一个比 1 小的数，结果会比原来的数小。现在去方格纸上看看。

## 5–20 分钟：实验

### 一张方格纸就是 1

在 10×10 的方格纸上，沿外边画一个大正方形。

家长：整个正方形，我们把它看成 1。横着有几小格？竖着有几小格？

孩子：10 格，10 格。

家长：那一小格是多少？

孩子：一百分之一，0.01。

家长：对。整个是 1，一小格是 0.01。

### 涂出 0.3 和 0.4

家长：0.3 是几个十分之一？

孩子：3 个。

家长：在图上涂 3 列。

孩子涂 3 列。

家长：0.4 呢？

孩子：4 个十分之一，涂 4 行。

孩子涂 4 行。两色重叠的地方，出现 12 个小格。

家长：数一数，重叠了几小格？

孩子：12 格。

家长：一小格是 0.01，12 小格是多少？

孩子：0.12。

家长：所以 0.3×0.4 等于多少？

孩子：0.12。

家长：你刚才猜的 1.2，差在哪？

孩子：1.2 是 120 个小格，太大了。

### 再试一个

家长：0.2×0.5 呢？先涂，再数。

孩子：2 列，5 行，重叠 10 小格，是 0.10，也就是 0.1。

家长：0.10 和 0.1 一样大吗？

孩子：一样，末尾的 0 可以去掉。

### 记录

在纸上写三行：

```
我猜：0.3×0.4 = 1.2
我看到：重叠 12 个小格
我发现：0.3×0.4 = 0.12
```

## 20–35 分钟：讲解

家长：不看图，我们能不能直接算？

家长：0.3 是 3 个十分之一，0.4 是 4 个十分之一。3×4=12，这个 12 是什么？

孩子：12 个……百分之一？

家长：对。十分之一乘十分之一，得到的是百分之一。所以 12 个百分之一，就是 0.12。

家长：这就是小数乘法的根：先按整数乘，再看两个因数一共有几位小数。

### 例 1：2.4×1.3

家长：先不看小数点，24×13 等于多少？

孩子：312。

家长：2.4 有几位小数？1.3 有几位？

孩子：各 1 位，一共 2 位。

家长：从右边数 2 位，点上小数点。

孩子：3.12。

家长：估算一下，2.4×1.3 大约是多少？

孩子：2.4×1=2.4，3.12 差不多。

### 例 2：0.25×0.4

家长：25×4=100。0.25 有 2 位小数，0.4 有 1 位，一共 3 位。

家长：从右边数 3 位，点小数点。

孩子：0.100。

家长：末尾的 0 怎么办？

孩子：去掉，等于 0.1。

家长：对。先点小数点，再化简。顺序不要反。

### 一句话

家长：小数点不是自己会“搬家”。是每个数位在缩放。两个因数一共有几位小数，积就有几位小数。

## 35–50 分钟：四个问题

### 1. 你看到了什么

家长：用一句话说，刚才实验看到了什么？

孩子：0.3 乘 0.4，重叠了 12 个小格，就是 0.12。

### 2. 为什么

家长：为什么 3×4=12，到了小数里就变成 0.12？

孩子：因为 0.3 和 0.4 都是十分之几，乘出来是百分之几。

如果孩子说不清，回到方格纸，指着一小格问：“这一格是多少？”

### 3. 你怎么证明

家长：除了方格纸，还能怎么证明？

孩子：可以算 0.3×0.4，再看 0.12÷0.4 是不是 0.3。

家长：对，乘法和除法可以互相检验。

### 4. 改一个条件

家长：0.3×0.04 呢？

孩子：3×4=12，三位小数，0.012。

家长：1.2×0.3 呢？

孩子：12×3=36，两位小数，0.36。

家长：0.3×0.4 再乘 10 呢？

孩子：0.12×10=1.2。

## 50–65 分钟：挑战

### A 层

1. 0.6×0.7
2. 1.5×0.4
3. 0.25×8

答案：0.42，0.6，2。

### B 层

1. 0.125×0.8
2. 2.4×1.25
3. 0.03×0.4
4. 小明写：0.3×0.4=1.2。他错在哪？

答案：

1. 125×8=1000。0.125 有 3 位小数，0.8 有 1 位，一共 4 位，所以是 0.1000=0.1。
2. 24×125=3000。2.4 有 1 位小数，1.25 有 2 位，一共 3 位，所以是 3.000=3。如果只数两位，就会错成 30。
3. 3×4=12，三位小数，0.012。
4. 他只算了 3×4=12，没有数小数位数；0.3×0.4 应该是 0.12。

### C 层

两个小数相乘，积一定比每个因数都小吗？

答案：不一定。

- 0.3×0.4=0.12，比两个因数都小。
- 1.5×2=3，比 1.5 大，也比 2 大。
- 0.5×2=1，等于 2 的一半，比 0.5 大，比 2 小。

规律：两个因数都小于 1，积才小于每个因数；只要有一个因数大于 1，积就可能变大。

## 65–75 分钟：复述与原理卡

让孩子讲：为什么 0.3×0.4 不是 1.2？

家长只问：为什么？画给我看？如果改成 0.03×0.4 呢？

原理卡：

```
【课题】小数乘法
【本课要点】先按整数乘，再按两个因数的小数位数和点小数点。
【一张图】10×10 方格，3 列乘 4 行，重叠 12 小格 = 0.12。
【一个反例】0.3×0.4 不是 1.2；1.2 是 120 个小格。
【还没想通的问题】
```

## 常见错误

| 错误 | 怎么接 |
|---|---|
| 0.3×0.4=1.2 | 问“1.2 比 0.3 大还是小？乘 0.4 应该变大吗？” |
| 积的小数位数数错 | 回到“每个因数有几位小数”，把位数写在因数上面 |
| 末尾 0 先去掉再点小数点 | 先点小数点，再化简；顺序不能反 |
| 2.4×1.25=30 | 估算 2.4×1.25 大约 3，不是 30；再数位数 |
| 认为小数点会自己搬 | 回到方格纸，指着一小格说“这是 0.01” |
