# 第 7 课 动手单：等式与方程

**今天的大问题**：天平为什么能帮你解方程？

**材料**：天平或衣架平衡尺、纸袋、小方块/硬币、白纸、彩笔

## 1. 做一台天平

用衣架或天平做平衡。纸袋里放一些方块，袋子上写 x。

画一画：

```
左边：x + 3        右边：8
```

两边平衡吗？__________

## 2. 解 x+3=8

要让左边只剩 x，两边各拿走几个方块？

__________ 个。

拿走以后：

- 左边：__________
- 右边：__________
- 所以 x=__________

代回去检查：__________ + 3 = 8。

## 3. 解 2x=10

两个一样的袋子，左边一共 2x；右边 10 个方块。

两边都分成 2 份：

- 一份是 __________；
- 所以 x=__________。

代回去检查：2 × __________ = 10。

代回去检查：2×__________ + 3 = __________ + 7。
