# 第 7 课 挑战单：等式与方程

## 基础挑战：画图或用算术求数

1. 一个数加 4 得 9，这个数是多少？
2. 三个同样大的数合起来是 12，每个数是多少？
3. 一个数减 2 得 6，这个数是多少？
4. 两袋同样重的物品加 1 个单位砝码，共重 11 个单位，每袋重多少？

答案：9−4=5；12÷3=4；6+2=8；(11−1)÷2=5 个单位。把各题的答案放回题目检查。

**对应课**：五上 07 等式与方程

**用法**：先说要做什么运算，再解，最后代回去。答案在后面。

## A 组：先练基础

1. x+4=9
2. 3x=12
3. x−2=6

## B 组：换个问题

1. 2x+1=11
2. 5x−5=20
3. 小明解 x+3=8，写成 x=8+3=11。他错在哪？

## C 组：多想一步

1. 2x+3=x+7
2. 为什么方程两边不能同除以 0？
3. 方程两边同乘 0，等式还成立吗？为什么解方程不这样做？

## 答案与说明

### A 组：先练基础

1. x=5。两边减 4；5+4=9。
2. x=4。两边除以 3；3×4=12。
3. x=8。两边加 2；8−2=6。

### B 组：换个问题

1. x=5。两边先减 1，2x=10；再除以 2。
2. x=5。两边先加 5，5x=25；再除以 5。
3. 他在左边去掉 3，相当于减 3，右边却加了 3，两边做了不同的运算；应该两边都减 3，x=5。代回去 5+3=8。

### C 组：多想一步

1. x=4。两边减 x 得 x+3=7，再减 3 得 x=4。
2. 0 不能作除数；除以 0 没有意义，天平也不能平均分成 0 份。
3. 仍成立，因为两边都变成 0；但原来的信息丢失了，不能倒回去求 x。所以解方程不用同乘 0。

## 做完再检查

- 方程必须同时有未知数和等号；5+4=9 是等式，但没有未知数，不是方程。
- 两边做同一件事，等式才保持相等。
- 同除的数不能是 0；同乘 0 虽然仍相等，但会丢失信息，不能用来解方程。
- 解完要代回原方程检查，不能只检查变形后的式子。
- 未知数要用同一个值代入，不能一半当 5、一半当 3。
