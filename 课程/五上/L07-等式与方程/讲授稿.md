# 第 7 课：等式与方程

含有未知数的等式叫方程。解方程时，让两边一起加减同一个数，或乘除同一个非零的数，逐步算出未知数是多少。

## 等式两边怎样一起变

等式像一架平衡的天平：左边和右边一样重，中间用等号连接。

如果两边同时加上、减去同一个数，或者同时乘同一个数，天平仍然平衡，等式仍然成立。两边同时除以一个数也可以，但这个数不能是 0，因为 0 不能作除数。

解方程就是利用这一点，把包在未知数外面的运算一层层去掉：

- x+3=8，两边同时减 3，左边只剩 x，右边 8−3=5，所以 x=5；
- 2x=10，两边同时除以 2，左边剩 x，右边 10÷2=5，所以 x=5。

每一步都要在两边做同样的事。只在一边减 3，天平就歪了，等式不再成立。

这些步骤要能倒过来做：加 3 后可以减 3，乘 2 后可以除以 2。但两边都乘 0，就只剩下 0=0，看不出 x 应该是多少了；也不能再除以 0 回到原式。所以解方程时不用两边同乘 0。

方程和式子、等式的区别：

- x+3 是式子，没有等号；
- 5+4=9 是等式，但没有未知数，不是方程；
- x+3=8 既含未知数，又是等式，是方程。

解完要代回原方程检验。x=5 代入 x+3=8，左边 5+3=8，等于右边，解正确。

## 例子

### 例 1：x+3=8

两边同时减 3：

x+3−3=8−3

x=5

检验：5+3=8。

### 例 2：2x=10

两边同时除以 2：

2x÷2=10÷2

x=5

检验：2×5=10。

### 例 3：2x+3=x+7

两边先同时减 x：

2x+3−x=x+7−x

x+3=7

两边再同时减 3：

x=4

检验：左边 2×4+3=11，右边 4+7=11，相等。

## 易错

- 只在一边加减。x+3=8 应两边同时减 3，得 x=5；写成 x=8+3=11 是只在右边动了。
- 把 x+3 叫方程。没有等号，它只是式子。
- 把 5+4=9 叫方程。它是等式，但没有未知数。
- 两边同除以 0。0 不能作除数，这一步没有意义。
- 用同乘 0 来“解”方程。0=0 虽然成立，但信息丢了，求不出 x。
- 移项时符号弄反。x−2=6，两边同时加 2，x=8；不是 x=4。
- 解完不检验。代回原方程，两边相等才算解对。
- 只对等式一边的某一项做除法。2x+3=11，先减 3 再除以 2 很简便；也可以两边整体先除以 2，得 x+1.5=5.5，再减 1.5 得 x=4。不能只除 2x 而留下 3 不变。

## 练习

1. x+4=9
2. 3x=12
3. x−2=6
4. 2x+1=11
5. 5x−5=20
6. 2x+3=x+7

## 答案

1. 两边减 4，x=5。检验：5+4=9。
2. 两边除以 3，x=4。检验：3×4=12。
3. 两边加 2，x=8。检验：8−2=6。
4. 两边减 1，2x=10；再除以 2，x=5。检验：2×5+1=11。
5. 两边加 5，5x=25；再除以 5，x=5。检验：5×5−5=20。
6. 两边减 x，x+3=7；再减 3，x=4。检验：左边 2×4+3=11，右边 4+7=11。
