LESSON 07 · 五上

第 7 课：等式与方程

天平为什么能帮你解方程？

动手单挑战单课程目录
实验→讲解→四问→挑战→复述
本课要点方程是一个含未知数的等式；解方程就是在等式两边做同一件可逆的事，让未知数单独留下。两边同乘一个数仍相等；同除时除数不能为 0。解方程不用同乘 0，因为会把原来的限制冲掉。
时长75 分钟
建议每周 1 课，允许一节课只做一个实验
材料天平或衣架平衡尺、纸袋、若干小方块/硬币、白纸、彩笔

0–5 分钟：开场

家长：一个纸袋里有一些小方块，不知道几个。袋子上写 x。左边放袋子和 3 个方块，右边放 8 个方块。天平平衡。袋子里有几个？

孩子：5 个？

家长：先别猜。我们让天平自己告诉我们。

5–20 分钟：实验

x+3=8

家长：左边是 x+3，右边是 8。两边一样重，写成等式就是 x+3=8。

家长：要让左边只剩袋子，怎么办？

孩子：把 3 个方块拿掉。

家长：只拿左边会怎样？

孩子：左边轻了，不平衡。

家长：所以两边都要拿掉 3 个。右边 8−3=5，左边只剩 x。所以 x=5。

家长：把 5 放回袋子，左边 5+3=8，和右边相等。这个 5 就是方程的解。

2x=10

家长：两个一样的袋子，左边一共 2x；右边 10 个方块，平衡。一个袋子几个？

孩子：把两边都分成两份。

家长：对。左边分成 2 份，每份 x；右边分成 2 份，每份 5。所以 x=5。

家长：这也是在两边做同一件事：都除以 2。除数 2 不是 0。

20–35 分钟：讲解

家长：什么是方程？

孩子：有未知数，又是等式。

家长：x+3 是式子，不是方程；x+3=8 才是方程。方程像一个“带问号的天平”。5+4=9 是等式，但没有未知数，所以不是方程。

家长：解方程时，每一步都要让等式仍然成立。两边同加、同减、同乘一个数，仍然相等；两边同除一个数时，这个数不能是 0，因为除以 0 没有意义。

家长：为什么解方程不用两边同乘 0？

孩子：因为 0 乘任何数都是 0，原来的信息没了。

家长：对。x=3 时，两边同乘 0 会变成 0=0，看起来还相等，但已经看不出 x 是 3 还是别的数。解方程要用能倒回去的操作。

一句话

家长：方程是天平；解方程是在两边做同一件可逆的事，把未知数单独留下。

35–50 分钟：四个问题

1. 你看到了什么

家长：x+3=8，天平两边发生了什么？

孩子：左边有袋子和 3 个，右边 8 个，两边一样重。

2. 为什么

家长：为什么两边都要拿掉 3 个？

孩子：只拿一边就破坏了平衡；两边做同样的事，才仍然相等。

3. 你怎么证明

家长：怎么检查 x=5 对不对？

孩子：把 5 放回袋子，5+3=8，成立。

家长：对，代入原方程检验。

4. 改一个条件

家长：2x+3=x+7，还能用天平想吗？

孩子：两边各拿走一个袋子，左边剩 x+3，右边 7；再两边拿走 3，x=4。

家长：对。两边同时减去 x，再做一次同样的减法。代回去：2×4+3=11，4+7=11。

50–65 分钟：挑战

A 层

  1. x+4=9
  2. 3x=12
  3. x−2=6

答案：5；4；8。

B 层

  1. 2x+1=11
  2. 5x−5=20
  3. 小明解 x+3=8，写成 x=8+3=11。他错在哪？

答案：

  1. 5。两边先减 1，2x=10，再除以 2。
  2. 5。两边先加 5，5x=25，再除以 5。
  3. 他只在右边加了 3，没有在左边做同样的事；应该两边都减 3，x=5。代回去 5+3=8。

C 层

  1. 2x+3=x+7
  2. 为什么方程两边不能同除以 0？
  3. 方程两边同乘 0，等式还成立吗？为什么解方程不这样做？

答案：

  1. x=4。两边减 x 得 x+3=7，再减 3 得 x=4。
  2. 0 不能作除数；除以 0 没有意义，天平也没有“平均分成 0 份”。
  3. 仍成立，因为两边都变成 0；但原来的信息丢失了，不能倒回去求 x。所以解方程不用同乘 0。

65–75 分钟：复述与原理卡

让孩子讲：为什么解方程要在两边做同一件事？

家长只问：方程和式子差在哪？为什么同除的数不能是 0？同乘 0 为什么不能用？

原理卡：

【课题】等式与方程
【本课要点】方程是含未知数的等式；两边做同一件可逆的事，等式仍成立。
【一张图】x+3=8，两边各拿走 3，x=5。
【一个反例】两边同乘 0 会变成 0=0，信息丢了。
【还没想通的问题】

常见错误

错误 怎么接
只在一边加减 问“另一边也做了吗？天平还平吗？”
把 x+3 叫方程 没有等号，只是式子
2x=10 写成 x=10÷2 但不解释 可以，但要说出“两边都除以 2”
认为同乘 0 也能解方程 等式成立但信息丢失，不能倒推 x
同除以 0 0 不能作除数；这一步没有意义
