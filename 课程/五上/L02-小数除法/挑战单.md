# 第 2 课 挑战单：小数除法

**对应课**：五上 02 小数除法

**用法**：先讲“为什么两个数一起变”，再算。答案在后面。

## A 层

1. 0.8÷0.2
2. 2.4÷0.6
3. 0.45÷0.5

## B 层

1. 1.2÷0.03
2. 0.36÷0.04
3. 4.8÷0.12
4. 小明写：1.2÷0.3=0.4。他错在哪？用乘法检查。

## C 层

1. A÷B=4，A 和 B 同时乘 10，商是多少？
2. A×10，B 不变，商怎么变？
3. A 不变，B×10，商怎么变？

## 答案与说明

### A 层

1. 4。0.8÷0.2 = 8÷2。
2. 4。2.4÷0.6 = 24÷6。
3. 0.9。0.45÷0.5 = 4.5÷5 = 0.9。

### B 层

1. 40。1.2÷0.03 = 120÷3。
2. 9。0.36÷0.04 = 36÷4。
3. 40。4.8÷0.12 = 480÷12。
4. 0.3×0.4=0.12，不是 1.2，所以 0.4 不对。正确是 12÷3=4。他可能只把除数变成了整数，被除数没有跟着变。

### C 层

1. 4。两个数同时乘 10，商不变。
2. 商乘 10。被除数扩大 10 倍，除数不变，每份不变，份数变多。
3. 商除以 10。除数扩大 10 倍，被除数不变，份数变少。

## 边界

- 除数不能是 0。
- 被除数和除数要同时乘同一个 10 的幂。
- 小数点移动的位数，以除数为准；被除数位数不够要补 0。
- 除不尽时，商可能是循环小数，下一课讲。
